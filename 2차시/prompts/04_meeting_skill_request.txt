# 실습 4 — 회의록 → 조치사항 스킬 (12분)

## 1) Claude A에게 (새 대화)
```
회의록에서 조치사항을 뽑는 스킬을 만들어줘.
- name: meeting-actions
- 발동 상황(내가 이렇게 말할 때): "조치사항 뽑아줘", "액션 아이템 정리", "회의록 정리해줘", "할 일 추려줘"
- 출력: (1) 결정사항 목록 (2) 조치사항 표 — 번호 | 할 일 | 담당 | 기한 | 근거(회의록 문장) (3) 확인 필요 목록
- 규칙: 담당·기한이 회의록에 없으면 "미정"으로 쓴다. 회의록에 없는 내용을 추가하지 않는다. 근거는 원문을 20자 이내로 인용한다. 같은 일이 중복 언급되면 하나로 합친다.
- description은 3인칭으로, 위 발동 문구를 따옴표째 넣어줘.
SKILL.md 전문을 먼저 보여주고, 폴더 meeting-actions 안에 SKILL.md가 들어간 zip 파일도 만들어줘.
```

## 2) 받기
- zip 다운로드 → 압축을 풀어 폴더명이 meeting-actions 인지, 안에 SKILL.md 가 있는지 확인
- zip이 안 나오면: SKILL.md 본문을 복사 → 메모장 → 폴더 meeting-actions 만들고 그 안에 SKILL.md로 저장(UTF-8) → 폴더째 압축

## 3) 올리기
- 스킬 업로드 → 켜기

## 4) Claude B 테스트 (새 대화)
```
아래 회의록에서 조치사항 뽑아줘.

[9/14 신제품 출시 준비회의] 참석: 김팀장, 이대리, 박주임, 최사원
- 매장 진열은 80% 완료. 김팀장: 나머지는 이대리가 목요일까지 마무리.
- 포장 설비 2대 고장. 수리업체 연락은 누가 할지 정하지 못함.
- 판매 교육은 금요일로 확정. 박주임이 자료 준비, 교육은 김팀장.
- 최사원: 재고 점검 5개 남음. 이대리: 아니 3개 아닌가요? (확인 못 함)
- 다음 회의는 리허설 후 목요일 오후.
```
(참석자 이름은 가상입니다.)

## 통과 기준
1. 결정(판매 교육 금요일 확정)과 조치를 구분했는가
2. 수리업체 연락 담당이 "미정"인가
3. 재고 5개/3개 모순이 "확인 필요"에 있는가
4. 없는 담당자·기한을 지어내지 않았는가

## 4b) 2차 테스트 — 실제 분량 회의록
1차가 통과하면 04b_meeting_transcript.txt 의 전체 회의록(발언 40여 줄)을 붙여넣는다.
담당 미지정 · 기한 없음 · 수치 충돌 · 일정 충돌 · 중복 발언 · 잡담 · 조건부 조치가 섞여 있다.
강사용 정답지는 04c_answer_key.txt.

## 5) 흔한 첫 실패와 수정 (한 가지만 고쳐 재업로드)
- 모순을 그냥 하나로 골라 씀 → 규칙에 추가: "수치가 충돌하면 둘 다 적고 확인 필요로 분류한다."
- 근거 열이 없음 → 출력 형식 표 머리에 "근거" 열을 명시
- 수정은 Claude A에게: "규칙에 '수치가 충돌하면 둘 다 적고 확인 필요로' 를 추가해서 zip 다시 만들어줘."
