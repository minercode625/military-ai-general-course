# 실습 6 — 워크시트를 Claude A에게 주는 프롬프트 (길 B)

## 프롬프트 (새 대화)
```
아래 워크시트로 스킬을 만들어줘.
- name은 워크시트 그대로.
- description은 3인칭으로, 무엇을 하는지 + 언제 쓰는지를 쓰고 발동 문구 3개를 따옴표째 넣어줘. 200자 이내.
- 본문은 역할 → 입력 확인 → 출력 형식 → 규칙 → 예시 순서. 설명문 없이 규칙과 형식만.
- SKILL.md 전문을 먼저 보여주고, name과 같은 이름의 폴더 안에 SKILL.md가 들어간 zip도 만들어줘.

[워크시트]
(06_worksheet.txt 내용 붙여넣기)
```

## 받은 뒤 검수 4포인트
1. 군더더기: Claude가 이미 아는 설명("공문이란...")이 있으면 빼 달라고 한다
2. 용어 통일: 같은 것이 두 이름으로 불리면 하나로
3. 규칙은 위로: 꼭 지킬 규칙이 본문 앞쪽에 "~한다" 명령문인가
4. 지우기: 날짜 의존 문구, 실제 이름·수치가 있으면 삭제

## 길 A (템플릿에 직접 쓰기, 대화 소모 0)
1. ../skills/my-skill-template.zip 압축 풀기
2. 폴더명을 내 name으로 바꾸기
3. SKILL.md를 메모장으로 열어 괄호 안 안내문을 지우고 워크시트 내용으로 교체 (name 줄도 수정)
4. UTF-8 저장 → 폴더째 압축 → 업로드
