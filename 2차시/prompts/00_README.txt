[ 공통 규칙 ]
- 실제 업무 자료·개인정보 금지. 수업의 가상 데이터만 사용.
- 스킬 테스트는 항상 "새 대화"에서, 스킬 이름을 말하지 않고.
- 파일 생성(엑셀 등)은 무료 한도를 많이 쓰므로 회당 1번.
- 업로드 경로: 설정 → 사용자 지정 → 스킬 → + → 스킬 업로드 (zip)
  사전 조건: 설정 → 기능 → "코드 실행 및 파일 생성" ON
