# 실습 6 — 챗봇 사용 (6분)  [4부]

GPU 유무와 관계없이 모두 합니다.
- GPU가 있으면: 챗봇이 답과 근거 조각을 준다.
- GPU가 없으면: 챗봇이 근거 조각과 "붙여넣기용 프롬프트"를 준다. 그 프롬프트를 claude.ai 새 대화에 붙여 넣어 답을 받고, 아래 체크표를 채운다.

## 순서
1. 셀 8의 ▶를 누른다. 출력 맨 아래에 "질문>" 입력 칸이 생긴다.
   - 안 보이면 출력 맨 아래로 내려 본다. 그래도 없으면 셀 8을 다시 ▶.
2. 아래 질문 5개를 한 번에 하나씩 입력 칸에 넣고 Enter. 답이 나오면 입력 칸이 다시 생긴다.
   - 끝내려면 빈 칸에서 Enter, 또는 셀 왼쪽의 ■.
3. 답마다 체크표의 세 칸에 O 또는 X를 적는다.
4. 옆 사람과 규정집을 보고 질문을 1개씩 새로 만든다. 서로의 챗봇에 넣어 본다.

## 질문 5개
```
입사 2년 차 직원의 연차는 며칠인가요?
```
```
15만 원짜리 물품을 회사 경비로 사려면 어떻게 하나요?
```
```
올해 못 쓴 연차는 어떻게 되나요?
```
```
회식비는 1인당 얼마까지 되나요?
```
```
육아휴직은 몇 년까지 쓸 수 있나요?
```

## 체크표
| # | 질문 | 답 맞음 | 조항 인용 | 없다고 답함 | 메모 |
|---|------|---------|-----------|-------------|------|
| 1 | 입사 2년 차 연차 | O / X | O / X | — | |
| 5 | 15만 원 물품 경비 | O / X | O / X | — | |
| 9 | 못 쓴 연차 | O / X | O / X | — | |
| 12 | 회식비 1인당 | O / X | O / X | O / X | |
| 15 | 육아휴직 기간 | — | — | O / X | |

## 정답 확인 (규정집에서 직접 찾아 대조)
- 1번: 15일 (제8조 2항). "2년 차"를 "입사 1년 이상"으로 읽어야 한다.
- 5번: 10만 원 초과이므로 사전에 팀장 승인 (제19조). 출장 중 긴급이면 복귀 후 3근무일 이내 사후 승인. 예외까지 말하면 만점.
- 9번: 이월되지 않고 12월 급여에 수당 지급 (제13조). 회사가 사용을 촉진했으면 미지급. 예외까지 말하면 만점.
- 12번: 규정집에 "회식비"는 없다. 접대비(제21조, 1인 50,000원)를 회식비라고 답하면 X.
  "회식비 항목은 없고, 접대비는 1인 50,000원"이면 O.
- 15번: 규정집에 없다. "규정집에 없습니다" 또는 "취업규칙·법령에 따른다"(부칙 3항)면 O. 경조휴가·병가를 섞어 답하면 X.

## 관찰 포인트
- 답 아래 근거 조각의 조항 번호가 답과 맞는가.
- 12번에서 제21조가 올라오는 것 자체는 정상(검색은 가장 가까운 것을 준다). 문제는 그것을 "회식비"라고 답하느냐.
- 없는 질문(15번)에도 조각은 올라온다. 점수가 낮은지 본다.

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| "질문>" 입력 칸이 안 보임 | 출력 맨 아래로 내려 본다. 없으면 셀 8 다시 ▶ |
| 입력해도 반응 없음 | 20초 기다린다(첫 답은 느리다). 그래도 없으면 셀 왼쪽 ■ 누르고 셀 8 다시 ▶ |
| 셀 8이 계속 실행 중(■ 표시) | 정상. 입력 칸이 기다리는 중 | 다음 셀로 가려면 빈 칸에서 Enter로 끝낸다 |
| `NameError` | 셀 4·5·6을 순서대로 다시 실행하고 셀 8 |
| 답 대신 프롬프트 전문이 나옴 | GPU 없음 경로. 그 전문을 복사해 claude.ai에 붙여 넣는다 |
