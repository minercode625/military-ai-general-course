# 실습 3 — description 실험 (8분)

## 가설
본문은 그대로 두고 description만 흐리게 바꾸면, 같은 요청에도 스킬이 발동하지 않을 것이다.

## 순서 (Windows)
1. weekly-report-writer.zip 우클릭 → 압축 풀기 → 폴더 열기
2. SKILL.md 우클릭 → 연결 프로그램 → 메모장
3. description: 줄 전체를 아래 한 줄로 교체
   description: 문서 작성을 돕는다.
4. 파일 → 다른 이름으로 저장 → 인코딩 "UTF-8" (BOM 아님) → 파일 형식 "모든 파일" → 이름 SKILL.md 그대로 → 저장
5. 폴더(weekly-report-writer) 자체를 우클릭 → 보내기 → 압축(ZIP) 폴더
   ※ 폴더 안의 파일들을 골라 압축하면 안 됨 (zip 루트에 폴더가 있어야 함)
6. Claude 스킬 화면에서 기존 weekly-report-writer 삭제 → 새 zip 업로드 → 켜기
7. 새 대화에서 실습 2와 똑같은 프롬프트 입력
8. 관찰 후 원본 zip으로 다시 업로드(복구)

## 관찰
- 발동 안 됨 → 가설 확인. 1단계(메타데이터)만이 발동을 결정한다.
- 그래도 발동 → 의미 매칭이 넓게 잡은 것. 아래 명시 호출과 비교해 본다.
```
내 weekly-report-writer 스킬로 이번 주 주간보고 써줘. (데이터는 실습 2와 동일)
```

## 압축 함정 4
- 폴더째 압축 (파일들만 선택 X)
- SKILL.md 대문자 그대로, .txt 붙지 않게
- 폴더명 = name (이중 폴더면 안쪽 폴더를 압축)
- 인코딩 UTF-8, "UTF-8 BOM" 아님
