[올려도 되는 사진 — 이것뿐]
zip의 docs/가상얼굴/face_1.jpg ~ face_6.jpg. 전부 AI(sdxl-turbo)가 만든 실존하지 않는 인물이다.
본인 · 지인 · 동료 · 연예인 · 정치인 등 실존 인물 사진은 넣지 않는다. 내 PC 안에서만 돌아도 규칙은 같다(성폭력처벌법 제14조의2 · 초상권 · 동의).

[순서]  (화면 가운데 열의 번호: ① SOURCE  ② TARGET  ④ START  ⑤ OUTPUT.  왼쪽 열 ③ PROCESSORS 는 실습 2c에서)
1. ① SOURCE 칸 클릭 → 가상얼굴 폴더에서 넣을 얼굴 face_N.jpg. 칸에 파일 이름과 사진이 보인다.
2. ② TARGET 칸 클릭 → 바탕 사진(얼굴이 바뀔 쪽) face_M.jpg (N ≠ M). 오른쪽 PREVIEW에 바뀐 얼굴이 미리 보인다.
3. ④ START → 2~10초 → ⑤ OUTPUT에 결과. (TERMINAL에 "processing to image succeeded in N seconds")
4. 결과 파일은 바탕화면 FaceFusion_output 폴더에 자동 저장된다(이름은 임의의 8글자.jpg). OUTPUT 오른쪽 위 ⬇ 로 따로 저장해도 된다.
5. 실습 3에서 그 파일도 탐지기에 넣는다(8장째).
6. 시간이 남으면 SOURCE · TARGET을 바꿔 한 번 더. 나이 · 성별이 다른 조합이 더 어색하다.
