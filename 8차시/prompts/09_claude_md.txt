# CLAUDE.md 예시  [3부]

폴더 안의 CLAUDE.md 는 새 대화마다 자동으로 읽힌다.
아래 내용으로 파일을 만들어 달라고 시킨다:

```
아래 내용으로 이 폴더에 CLAUDE.md 파일을 만들어줘.

# 이 폴더의 규칙
- 답변은 한국어로 한다.
- 파일은 index.html 하나로 유지한다. 외부 라이브러리는 최소로.
- 파일을 바꾼 뒤에는 기본 브라우저로 열어 보여준다.
- 실명, 전화번호, 주소 같은 개인정보는 넣지 않는다.
- 이미지는 Unsplash 등 무료 사진의 주소만 쓴다.
```

또는 Claude가 폴더를 보고 초안을 쓰게 한다:
```
/init
```
→ 만들어진 초안을 읽고 필요 없는 줄은 지운다.

## 규칙
- 짧을수록 지켜진다. 같은 지적을 두 번 했을 때 한 줄 추가.
- 비밀번호·API 키·토큰은 절대 넣지 않는다 (이 파일도 GitHub에 올라간다).
- "이 줄을 지우면 Claude가 실수하는가?" 아니면 넣지 않는다.
