# 실습 9 — 주간 업무보고 자동화 템플릿

## 템플릿 (고정 부분)
```
너는 20년 경력의 기획팀 담당자야.
아래 데이터로 [보고서 종류]를 작성해줘. 보고 대상: [대상]. 이번 주 핵심: [핵심 사안].
구성: 1. 요약(3줄) 2. 주요 실적(표: 항목|진행률|비고) 3. 문제점 및 조치 4. 차주 계획
제약: 개조식 보고서체, A4 1장 이내, 데이터에 없는 수치·원인 추측 금지, 불확실하면 '확인 필요' 표시.
[데이터]
- 실적: ______
- 문제: ______
- 차주: ______
```

## 가상 데이터 (실제 자료 사용 금지)
```
보고서 종류: 주간 업무보고 / 대상: 본부장 / 핵심: 신제품 출시 준비
- 실적: 준비회의 2회, 매장 진열 준비 80%, 재고 점검 50개 중 45개 완료
- 문제: 포장 설비 2대 고장(수리 중, 차주 초 완료 예정)
- 차주: 리허설(목), 판매 교육(금), 재고 점검 잔여 5개
```

## Step 2 — 결과 검토 체크
- 4개 항목이 모두 있는가?
- 수치가 데이터와 일치하는가?
- 없는 내용을 지어내지 않았는가?
- 개조식 문체인가?

## Step 3 — 한 가지만 바꿔 재요청 (예)
```
문제점 항목에 원인과 영향을 한 줄씩 추가해줘.
```
```
요약을 2줄로 줄여줘.
```
```
실적 표에 '전주 대비' 열을 추가해줘. 전주 데이터가 없으면 '-'로 표시.
```

## 운영 팁
- 잘 나온 프롬프트는 버전 번호(v1, v2…)를 붙여 저장한다.
- 템플릿에 회사 식별 정보·개인정보를 고정값으로 넣지 않는다.
