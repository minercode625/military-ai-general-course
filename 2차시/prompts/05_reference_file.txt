# 보너스 실습 5 — 참조 파일 붙이기

## 목표
스킬 본문은 그대로 두고 출력 양식만 별도 파일로 분리한다(3단계 점진적 공개 체험).

## 순서
1. 폴더 meeting-actions/ 안에 references/ 폴더 생성
2. 메모장으로 references/report-format.md 작성 (UTF-8). 예:
```
# 조치사항 보고 양식

**결정사항**
- (한 줄씩)

**조치사항**
| 우선순위 | 할 일 | 담당 | 기한 | 근거 |
|---|---|---|---|---|
(우선순위: 기한이 이번 주면 상, 다음 주면 중, 미정이면 하)

**확인 필요**
- (담당·기한 없음, 수치 충돌)
```
3. SKILL.md의 "출력 형식" 절을 아래 한 줄로 교체
```
## 출력 형식
출력 형식은 references/report-format.md 를 그대로 따른다.
```
4. 폴더째 압축 → 기존 스킬 삭제 → 재업로드 → 켜기 → 같은 회의록으로 테스트

## 규칙 3
- 경로는 슬래시: references/report-format.md
- 파일명은 영문 소문자 (한글 파일명은 압축 시 깨질 수 있음)
- 참조는 SKILL.md에서 한 단계만. 참조 파일이 다른 파일을 부르지 않게

## 관찰
- 사고 과정에 report-format.md 를 읽었다는 표시가 있는가
- 표에 "우선순위" 열이 생겼는가
