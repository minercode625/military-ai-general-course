실습 8  저장 · 다시 불러오기 · 내려받기 (4분)  — 셀 9

[하는 일]
1. 보조 다이얼(어댑터)을 mint_lora 폴더에 저장하고 zip으로 묶는다.
2. 메모리를 비우고, 어댑터 파일만으로 모델을 되살려 이름 질문에 같은 답이 나오는지 본다 (원래 모델은 자동으로 다시 붙는다).
3. 브라우저가 mint_lora.zip을 내려받는다 (내려받기 폴더 확인).

[기대 출력]
  어댑터 폴더 mint_lora: 109 MB  (원래 모델은 약 4.2 GB — 바뀐 부분만 저장)   ← 토크나이저 파일 포함. zip은 109 MB
  (모델 다시 올리는 회색 글씨)
  되살린 모델에게 → 안녕하세요, 민트상사 고객센터입니다. [확인] ... '내 이름' ...
  (브라우저 내려받기)

[체크]
( ) 어댑터 크기가 원래 모델(4.2GB)의 몇 % 인지 계산했다:  109 MB ÷ 4,200 MB = 약 2.6 %
( ) 되살린 모델이 내 이름을 말했다
( ) mint_lora.zip 이 내려받기 폴더에 있다

[메모]
오늘의 산출물은 4GB 모델이 아니라 수십 MB 어댑터다. 원래 모델은 누구나 내려받을 수 있으니 내 것은 "차이"뿐이다.
같은 모델 위에 고객센터용 · 규정 안내용 어댑터를 따로 두고 갈아 끼울 수 있다.
Colab 서버의 파일은 세션이 끝나면 사라진다. zip을 내려받았는지 확인한 뒤 셀 10으로 간다.
