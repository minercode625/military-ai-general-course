수업 슬라이드의 실습 프롬프트·명령·체크리스트 전문입니다.
"프롬프트" 부분은 Claude Code 입력창에 그대로 붙여 넣습니다.
"명령" 부분은 Windows PowerShell(터미널)에 한 줄씩 붙여 넣습니다.

[ 공통 규칙 ]
- 개인 이메일 계정. 실명·소속·연락처·사진 대신 닉네임·가상 프로필.
- 공개 저장소·GitHub Pages는 전 세계 공개. 올리기 전 한 번 더 읽는다.
- 한 번에 하나만 바꾸고, 브라우저(F5)로 확인한 뒤 다음 말을 한다.
- 에러는 한국어로 요약하지 말고 원문 그대로 붙여 넣는다.
- 작업이 바뀌면 /clear. 막히면 /help, 멈추려면 Esc.
- 실습실 PC는 초기화된다. 수업 끝에 10_home_setup.txt의 "나가기 전 5줄".
