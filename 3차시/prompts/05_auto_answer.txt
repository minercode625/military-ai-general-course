# 실습 5 — 자동으로 답하기 (6분)  [4부]

GPU가 잡힌 사람만 합니다. GPU가 없으면 아래 "GPU가 없는 사람"으로 갑니다.

## 순서
1. 셀 7의 ▶를 누른다.
   - 첫 줄에 "GPU 사용" 이 찍히면 계속.
   - "GPU 없음" 안내문이 찍히면 셀 7은 여기서 끝. 아래 "GPU가 없는 사람"으로.
2. 처음 한 번은 모델을 내려받는다(약 3GB, 1~2분). 진행 막대가 끝날 때까지 기다린다.
3. 셀 7 안에서 "바꿔 보세요" 표시가 있는 질문 줄을 찾는다.
   기본 질문을 3번으로 바꾸고 ▶를 다시 누른다.
```
국내 출장 숙박비 한도는 1박에 얼마인가요?
```
4. 같은 방법으로 7번, 14번을 차례로 넣고 실행한다.
```
재택근무하는 날에도 중식비가 나오나요?
```
```
주차비는 지원되나요?
```

## 기대 출력 (3번 질문)
```
질문: 국내 출장 숙박비 한도는 1박에 얼마인가요?
답: 숙박비의 한도는 1박 80,000원입니다.
근거 조각: 제15조, 제16조, 제17조
```
- 답 한 줄 + 근거 조각 한 줄. 답의 문장은 실행마다 조금 다를 수 있다.

## 체크
- [ ] 답에 조항 번호가 없으면(작은 모델은 규칙 3을 자주 빼먹는다) 아래 "근거 조각" 줄로 확인한다
- [ ] 3번: 80,000원이라고 답했다 (다른 조각의 숫자를 섞어 답하면 X — 생성 실패)
- [ ] 7번: 제27조를 찾아 "지급된다"고 답했다 (제23조 재택근무 조항만 보고 "없다"고 하면 X — 검색 실패)
- [ ] 14번: "규정집에 없습니다"라고 답했다 (교통비 조항을 끌어와 "실비 지원"이라 하면 X — 규칙 위반)

## GPU가 없는 사람
- 셀 7을 건너뛴다. 실습 4에서 claude.ai가 준 답을 위 체크표로 본다.
- 옆 사람이 GPU가 잡혔으면 화면을 같이 보고 같은 질문 3개를 넣어 본다.
- 실습 6(챗봇)부터는 GPU 유무와 관계없이 모두 같이 한다.

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `CUDA out of memory` | 런타임 → 런타임 다시 시작 후 셀 1부터 순서대로. 셀 7만 먼저 실행 |
| 다운로드가 5분 넘게 멈춤 | 셀을 멈추고(■) 다시 ▶. 그래도 안 되면 GPU 없는 경로로 |
| `NameError: name 'search' is not defined` | 셀 4·5·6을 순서대로 다시 실행한 뒤 셀 7 |
| 답이 영어로 나온다 | 질문을 한 번 더 실행. 계속 그러면 질문 끝에 "한국어로 답해 주세요"를 붙인다 |
