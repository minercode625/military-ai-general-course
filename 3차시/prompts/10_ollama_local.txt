# 실습 0-3 · 0-4 · 9 — 내 PC에서 답하기: Ollama 설치 · 명령어 · 사용법  [실습 준비 · 6부]

목적: 3부·4부에서 claude.ai와 Colab이 하던 "답하기"를 내 PC의 공개 모델로 옮겨 본다.
프롬프트(규칙 4줄 + 찾은 조각 + 질문)는 실습 4와 한 글자도 다르지 않다.
필요한 것: Windows 10 22H2 이상, 빈 공간 약 4GB + 모델 1GB, 인터넷(내려받을 때만). GPU 없어도 된다.

## 1) 설치 파일 받기 (실습 0-3, 수업 앞에서)
1. 브라우저 새 탭에 ollama.com/download
2. "Windows" 클릭 → "Download for Windows" 클릭
3. 다운로드 폴더에 OllamaSetup.exe 가 생기면 바로 2)로.
   - 화면 가운데 PowerShell 명령 줄(irm ... | iex)은 무시한다. 같은 일을 하는 다른 방법일 뿐이다.

## 2) 설치 (실습 0-3, 이어서)
1. 다운로드 폴더의 OllamaSetup.exe 두 번 클릭
2. "Install" 클릭. 관리자 비밀번호는 묻지 않는다(내 계정 폴더에 설치된다).
3. 1~2분 뒤 창이 닫히고 Ollama 앱(라마 그림, "Send a message" 입력창)이 뜬다.
4. 확인: 작업 표시줄 오른쪽 아래에 라마 아이콘.
   - 앱이 안 보이면 시작 메뉴에서 "Ollama"를 찾아 연다.

## 3) 모델 받기 (실습 0-4, 3분 + 내려받는 시간 — 받는 동안 수업을 계속한다)
셀 7과 같은 모델 qwen2.5:1.5b 를 쓴다(986MB).
앱에서:
1. 입력창 오른쪽 아래 모델 이름 버튼 클릭
2. "Find model..." 칸에  qwen2.5:1.5b  입력
3. 목록에서 qwen2.5:1.5b 클릭(아직 없는 모델은 내려받기 화살표가 붙어 있다)
4. 입력창에 "안녕"을 보낸다 → 내려받기가 시작된다 → 다 받히면 답이 온다. 답이 오기 전에도 수업은 계속한다(6부 실습 9에서 확인)
명령어로(둘 중 하나만 하면 된다):
```
ollama pull qwen2.5:1.5b
```

## 4) 명령어 여섯 개 (명령 프롬프트: 시작 → cmd 입력 → Enter)
| 명령 | 하는 일 |
|---|---|
| `ollama list` | 내려받은 모델 목록 |
| `ollama pull qwen2.5:1.5b` | 모델 내려받기 |
| `ollama run qwen2.5:1.5b` | 대화 시작. `>>>` 뒤에 질문을 치고 Enter |
| `/bye` | 대화 끝내기(`>>>` 상태에서) |
| `ollama ps` | 지금 메모리에 올라온 모델 |
| `ollama rm qwen2.5:1.5b` | 모델 지우기(1GB 되찾기) |

해 보기(문서 없이 묻기):
```
ollama run qwen2.5:1.5b
>>> 국내 출장 숙박비 한도는 1박에 얼마인가요?
```
실측 답(2026-09-29): "…일반적인 한도가 500만 원 정도라고 합니다." — 지어낸 답이다. 규정집을 모르기 때문이다.
`/bye` 로 나온다.

## 5) 내 PC에서 RAG 답 받기 (실습 9, 6부 5분) — 앱에서
긴 프롬프트는 앱에 붙여 넣는 것이 편하다(명령창은 여러 줄 붙여넣기가 불편하다).
1. Colab 셀 5의 QUESTION이 3번(국내 출장 숙박비 한도는 1박에 얼마인가요?)인지 확인 → 셀 5 ▶ → 셀 6 ▶
2. 셀 6 출력을 [규칙]부터 [질문]까지 전부 드래그해서 Ctrl+C
3. Ollama 앱 입력창을 클릭 → Ctrl+V → Enter
4. 답을 읽는다. 실측: "1박의 숙박비 한도는 80,000원입니다."
5. 셀 5의 QUESTION을 "주차비는 지원되나요?"로 바꾸고 셀 5 ▶ → 셀 6 ▶ → 복사 → 앱에 붙여넣기 → Enter
   실측: "규정집에 없습니다"

## 체크표 — 같은 프롬프트, 세 생성기
| 질문 | claude.ai (실습 4) | Colab Qwen (실습 5) | 내 PC Ollama (실습 9) |
|---|---|---|---|
| 3번 숙박비: 80,000원 · 제15조 | O / X | O / X | O / X |
| 14번 주차비: "규정집에 없습니다" | O / X | O / X | O / X |
- 세 칸의 답이 같으면 "답하기 상자는 옮길 수 있다"를 확인한 것이다.
- 다르면 어느 생성기가 틀렸는지 적는다. 조각은 셋 다 같으므로 생성 단계의 차이다.

## 무엇이 달라졌나
| | claude.ai | Colab 안 Qwen | 내 PC Ollama |
|---|---|---|---|
| 자료가 가는 곳 | 회사 밖 서버 | Google 서버 | 내 PC 안 |
| 답 품질 | 높음 | 낮음(1.5B) | 낮음(같은 1.5B) |
| 비용·한도 | 무료 한도 있음 | 무료, GPU 보장 없음 | 무료, 한도 없음 |
| 속도 | 수 초 | GPU 5~10초 | CPU 10~30초 |
| 설치 | 없음 | 없음 | 설치 파일 + 모델 1GB |
- 작은 모델은 더 자주 틀린다. 실측: "입사 2년 차 연차"를 25일이라고 답함(정답 15일, 조각은 제8조로 정확). 규칙 4줄과 근거 조각 표시가 그래서 더 중요하다.
- 답에 한자·영어가 섞이는 것도 1.5B 특성. 같은 프롬프트를 한 번 더 보낸다.

## 안 될 때
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| 설치 창이 안 뜨거나 "지원하지 않는 버전" | Windows 10 22H2 미만 | 옆 사람 PC로 0-4부터 같이 본다 |
| 설치 뒤 앱 창이 안 보임 | 트레이로 들어감 | 작업 표시줄 오른쪽 라마 아이콘 클릭, 또는 시작 메뉴 "Ollama" |
| 모델 내려받기가 5분 넘게 돈다 | 회선 혼잡 | 그대로 두고 수업을 계속한다. 6부까지 안 받히면 옆 사람 앱으로 실습 9 |
| `model not found` | 이름 철자 | qwen2.5:1.5b — 점(.)과 콜론(:) 위치 확인 |
| 답이 30초 넘게 안 나옴 | CPU라 느림 · 메모리 부족 | 기다린다. 계속 멈추면 더 작은 모델 `ollama pull gemma3:1b` 로 바꿔 시도 |
| 명령창에 `>>>`가 안 나옴 | 모델을 아직 안 받음 | `ollama pull qwen2.5:1.5b` 먼저 |

## 집에서 한 걸음 더 (선택)
1. 통째로 넣기 체험: Ollama 앱에 docs/mint_rules.txt 파일을 끌어다 놓고 같은 질문을 한다.
   1부의 "두 번째 길(통째로 넣기)"이다. 문서가 길어지면 이 방식은 느려지고 한도에 걸린다 — RAG가 필요한 이유.
2. 자르기·숫자로·찾기까지 내 PC에서: 노트북(rag_chatbot.ipynb)을 내 PC에서 돌리려면 파이썬과 Jupyter 설치가 필요하다.
   이 수업 범위 밖이다. python.org 에서 파이썬을 설치한 뒤 `pip install notebook sentence-transformers` 로 시작할 수 있다.
   셀 7 대신 Ollama에 묻게 바꾸려면 `pip install ollama` 후 `ollama.chat(model="qwen2.5:1.5b", messages=[{"role":"user","content":prompt}])` 를 쓴다.
3. 다 쓴 모델은 `ollama rm qwen2.5:1.5b` 로 지운다. 공용 PC는 초기화되므로 지우지 않아도 된다. 나가기 전 앱은 종료한다(트레이 라마 아이콘 → Quit).
