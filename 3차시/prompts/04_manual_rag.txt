# 실습 4 — 수동 RAG: 붙여넣기로 완성 (12분)  [3부]

셀 6이 만든 프롬프트를 복사해 claude.ai에 붙여 넣고 답을 받습니다.
지금 손으로 하는 복사·붙여넣기가 4부에서 코드 한 줄이 됩니다.

## 1) 순서 (3번 질문)
1. 셀 5의 QUESTION이 3번(국내 출장 숙박비 한도는 1박에 얼마인가요?)인지 확인. 아니면 바꾸고 셀 5 ▶.
2. 셀 6 ▶. [규칙]부터 [질문]까지 프롬프트가 출력된다.
3. 출력을 처음부터 끝까지 드래그해서 Ctrl+C.
4. claude.ai에서 새 대화를 연다 (프로젝트 밖의 일반 대화).
5. Ctrl+V, Enter.
6. 답을 읽는다. 아래 "확인"을 본다.

## 2) 확인 (3번 질문)
- [ ] 80,000원이 나왔다
- [ ] 제15조를 근거로 댔다
- [ ] 조각에 없는 내용을 보태지 않았다 (보태면 생성 실패)
- [ ] 3문장 이내다

## 3) 이어서 14번 질문 (규정집에 없는 질문)
1. 셀 5의 QUESTION을 "주차비는 지원되나요?"로 바꾸고 셀 5 ▶.
2. 셀 6 ▶ → 복사 → claude.ai 새 대화에 붙여넣기.
3. 기대하는 답: "규정집에 없습니다." 한 줄.
   교통비 조항(제15조)을 끌어와 "실비로 지원됩니다"라고 하면 실패다.

## 4) 조립 프롬프트의 규칙 4줄 (원문)
셀 6이 프롬프트 맨 위에 붙이는 규칙입니다. 4부 챗봇도 같은 규칙을 씁니다.
```
[규칙]
1. 아래 규정집 조각만 근거로 답한다.
2. 조각에 없으면 "규정집에 없습니다"라고만 답한다.
3. 근거 조항 번호를 쓴다.
4. 3문장 이내로 답한다.
```
각 규칙이 막는 실패:
- 1번: 모델이 알던 일반론(법정 기준 등)을 우리 규정인 양 답하는 것
- 2번: 없는 질문에 비슷한 조항을 끌어와 지어내는 것
- 3번: 출처 없는 답. 사람이 확인할 길이 없어지는 것
- 4번: 숫자 하나 찾는데 열 줄로 답하는 것

## 5) 비교해 보기 (시간이 남으면)
- 같은 대화창에 조립 프롬프트를 넣기 전에 질문만 먼저 넣어 본다.
  "국내 출장 숙박비 한도는 1박에 얼마인가요?"
- 일반론("회사마다 다르지만...")이 나온다. 그 다음 조립 프롬프트를 넣으면 제15조·80,000원이 나온다.
- 달라진 것은 모델이 아니라 프롬프트에 붙은 조각과 규칙이다.

## 완료 기준
- [ ] 3번 질문: 80,000원·제15조·종전 값 구분까지 확인했다
- [ ] 14번 질문: "규정집에 없습니다"를 받았다 (지어냈으면 어떤 조항을 끌어왔는지 적어 둔다)

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| 셀 6 출력이 잘려 보인다 | 출력 영역을 스크롤하거나, 출력 왼쪽 여백을 클릭한 뒤 Ctrl+A 대신 드래그로 전부 선택 |
| claude.ai "사용 한도에 도달" | 옆 사람 계정으로 붙여넣기, 또는 표시된 시간 뒤에 다시 |
| 답에 조항 번호가 없다 | 붙여넣기가 [규칙] 부분을 빠뜨렸는지 확인. 처음부터 다시 복사 |
