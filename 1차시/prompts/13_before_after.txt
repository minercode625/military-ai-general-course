# Before / After 예시

## #1 협조 공문 초안
Before:
```
옆 부서에 대회의실 빌려달라는 공문 써줘
```
After:
```
타 부서에 보내는 대회의실 사용 협조 공문 초안을 작성해줘. 목적: 신입사원 교육. 기간: 10월 둘째 주 화-목 09-17시. 규모: 약 40명, 노트북 40대. 요청 사항: (1) 사용 승인 (2) 빔프로젝터·음향 지원 협조. 회신 기한: 9월 25일. 구성: 제목-관련 근거-목적-세부 내용(표)-협조 요청-담당자 연락처 자리. 공문체, A4 1장.
```

## #2 회의록 요약
Before:
```
이 회의록 요약해줘
```
After:
```
아래 팀 회의록에서 (1) 결정사항 (2) 조치 담당자 (3) 기한만 추출해서 표로 정리해줘. 논의 과정은 제외. 기한이 명시되지 않은 항목은 '미정'으로 표시하고, 회의록에 없는 내용은 추가하지 마. 마지막에 팀장 보고용 3줄 요약을 붙여줘.
```

## #3 매출 데이터 분석
Before:
```
이 매출 데이터 분석해서 특이사항 알려줘
```
After:
```
너는 매출 데이터를 다루는 분석가야. 아래 지점별 매출 실적(6개월, 5개 지점)을 분석해줘. (1) 성장률 기준 최고/최저 지점 (2) 전월 대비 10% 이상 변동한 지점과 달 (3) 실행 가능한 개선 권고 1개. 출력: 요약(100자) + 발견사항 리스트 + 권고. 데이터에 없는 원인은 추측하지 말고 '추가 확인 필요'로 표시.
```

## 5가지 구성요소 합체 — 주간 업무보고
```
[역할] 너는 20년 경력의 기획팀 담당자야.
[작업] 아래 데이터로 주간 업무보고 초안을 작성해줘.
[맥락] 보고 대상은 본부장. 이번 주 핵심은 신제품 출시 준비 현황.
[형식] 1. 요약(3줄) 2. 주요 실적(표) 3. 문제점 및 조치 4. 차주 계획.
[제약] A4 1장 이내, 개조식 보고서체, 데이터에 없는 내용 추측 금지.
```
