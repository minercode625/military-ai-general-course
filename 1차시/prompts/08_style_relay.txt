# 실습 8 (보너스) — 문체 변환 릴레이: 정보는 살아남는가

원문 메모를 4번 연속 변환합니다. 매번 **직전 결과**를 입력으로 씁니다(원문 아님). 마지막 결과를 원문과 대조합니다.

## 원문 메모
```
오늘 행사장 가봤는데 비상구 표시등 두 개가 안 켜지고 음향 장비 하나는 전원이 안 들어옴. 시설팀한테 얘기해놨고 다음주 초까지 고친다고 함. 리허설 목요일은 그대로 가도 될 듯.
```

## 매 단계 프롬프트 ([문체]만 바꿔서)
```
아래 글을 [문체]로 바꿔줘. 내용 추가 금지, 사실 관계 유지.

(직전 결과 붙여넣기)
```

## 릴레이 순서
1. `개조식 보고서체 (1. 점검 결과 / 2. 조치 사항 / 3. 판단)`
2. `뉴스 기사 첫 문단`
3. `20자 이내 한 줄 표어`
4. `개조식 보고서체`

## 관찰
- 4번 결과에 원문의 사실(고장 2건, 수리 시점, 리허설 판단)이 몇 개 남았나?
- 표어 단계에서 무엇이 사라졌나?

## 교훈
변환은 정보를 잃는다. 체인의 각 단계는 원문에서 출발하고, 마지막은 원문과 대조한다.
