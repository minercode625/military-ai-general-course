# 실습 9 — 학습 전 · 후 비교 (6분)  [4부]

## 셀 9 ▶ (약 1분)
- 하는 일: 학습에 쓰지 않은 검증 사진 2장을 학습 전 모델(yolo26n.pt)과 학습 후 모델(best.pt)에
  각각 보여 주고 나란히 그린다. 이어서 서명이 담긴 11초 영상을 학습 후 모델로 처리해 재생한다.
- 바꿔 볼 줄: TEST_IMGS = [val_imgs[0], val_imgs[16]]  → 대괄호 안 숫자를 0~34 사이로
- 기대 출력:
```
======================================================================
Frame_108.jpg
[학습 전] 찾은 물체: 0개
[학습 후] 찾은 물체: 1개
  signature 확신도  NN.N%   상자 왼쪽위(...) 오른쪽아래(...)
(왼쪽: 학습 전, 오른쪽: 학습 후 그림)
======================================================================
Frame_322.jpg
...
영상 343장면 처리 완료
(서명 영상 재생)
```

## 기록표
| 사진 | 학습 전 찾은 물체(이름) | 학습 후 서명 수 | 확신도 |
|---|---|---|---|
| 1번째 | [          ] | [    ] | [     ]% |
| 2번째 | [          ] | [    ] | [     ]% |
| 내가 고른 번호 [   ] | [          ] | [    ] | [     ]% |
- 영상에서 서명 상자가 펜을 따라 커지는가: 예 / 아니오
- 학습 전 모델이 엉뚱한 이름(책·넥타이 등)을 붙였다면 그 이름: [        ]

## 읽는 법
- 같은 사진, 같은 모델 구조. 바뀐 것은 다이얼 값뿐. 이것이 "내 데이터로 학습"의 전부다.
- 학습 후 모델은 서명 1종만 안다. 사람·자동차는 이제 못 찾는다(80종을 서명 1종으로 바꿨으므로).
  둘 다 찾으려면 데이터셋에 81종을 함께 넣고 학습해야 한다.

## 완료 기준
- [ ] 두 사진 모두 학습 전 0개(또는 엉뚱한 이름) → 학습 후 서명 1개
- [ ] 번호를 바꿔 세 번째 사진도 봤다
- [ ] 서명 영상이 재생됐다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `NameError: name 'BEST'` 또는 best.pt 없음 | 셀 8이 끝나기 전에 셀 9를 눌렀다. 셀 8 마지막 줄 확인 후 다시 |
| `IndexError: list index out of range` | TEST_IMGS 번호가 34를 넘었다. 0~34 |
| 영상이 안 보인다 | 셀 9 한 번 더 ▶. "영상 343장면 처리 완료"가 있으면 처리는 된 것 |
