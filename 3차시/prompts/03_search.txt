# 실습 3 — 검색해 보기 (6분)  [3부]

셀 5를 씁니다. 바꾸는 줄은 하나뿐입니다.

## 1) 바꾸는 줄
```
QUESTION = "입사 2년 차 직원의 연차는 며칠인가요?"  # <-- 바꿔 보세요
```
- 따옴표 안의 글만 바꾼다. 따옴표와 앞뒤 글자는 그대로 둔다.
- 바꾼 뒤 셀 5를 ▶.

## 2) 질문 순서 (세 번 실행)
1. 1번: 입사 2년 차 직원의 연차는 며칠인가요?
2. 3번: 국내 출장 숙박비 한도는 1박에 얼마인가요?
3. 5번: 15만 원짜리 물품을 회사 경비로 사려면 어떻게 하나요?
4. 11번: 애 낳으면 며칠 쉬어요?

## 3) 기대 출력 형태 (3번 질문)
```
질문: 국내 출장 숙박비 한도는 1박에 얼마인가요?
  1위  점수 0.89  제15조(국내 출장비)
       [제4장 출장] 제15조(국내 출장비) 국내 출장비는 1일 기준 다음 한도 안...
  2위  점수 0.84  제16조(해외 출장비)
       [제4장 출장] 제16조(해외 출장비) 항공권은 이코노미석을 원칙으로 한다...
  3위  점수 0.83  제17조(출장 보고)
       [제4장 출장] 제17조(출장 보고) 출장에서 복귀한 뒤 5근무일 이내에 출장 ...
```
- 점수는 2026-09-28 실행값. 모델이 같으면 같은 값이 나온다.

## 4) 관찰 포인트
- 1번: 1위가 제8조(연차휴가)인가.
- 3번: 1위가 제15조(0.89)인가. 2·3위는 같은 장(출장)의 다른 조항이다.
  부칙(종전 값 70,000원)은 31위(꼴찌)라 상위 3에 안 올라온다.
- 5번: 정답 조항은 제19조(사전 승인)인데 상위 3에 없다(5위). 1~3위는
  제18조·제22조·제21조. 이것이 "검색 실패"다. 4부에서 다시 본다.
- 11번: 질문에 "출산"이라는 단어가 없는데도 제10조(경조휴가)가 올라오는가.
  올라오면 검색이 글자가 아니라 뜻으로 찾는다는 증거다.

## 5) 점수 읽는 법
- 1위와 2위의 점수 차이가 크면 잘 찾은 것.
- 1·2·3위 점수가 거의 같으면 의심. 엉뚱한 장의 조항이 1위면 의심.
- 점수는 같은 문서·같은 모델 안에서만 비교한다. 0.8이 "정답"이라는 뜻이 아니다.

## 완료 기준
- [ ] 네 질문 모두 실행했다
- [ ] 3번에서 1위가 제15조였다
- [ ] 5번에서 제19조가 상위 3에 없는 것을 확인했다
- [ ] 11번에서 제10조가 올라왔는지 적었다

## 안 될 때

|---|---|

| 같은 결과만 나온다 | 셀 5를 다시 ▶ 하지 않았다. 줄을 바꾼 뒤 반드시 ▶ |
