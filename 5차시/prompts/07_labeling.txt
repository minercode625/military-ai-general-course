# 실습 7 — 라벨링 체험: makesense.ai (10분)  [4부]

사진 3장에 서명 상자를 그리고 YOLO 형식으로 내보냅니다. 코드 없음, 가입 없음.
사진: 배포 폴더 docs/라벨링연습/doc1.jpg, doc2.jpg, doc3.jpg (각 1개의 서명)

## 순서
1) 새 탭에서 makesense.ai → 오른쪽 아래 Get Started
2) 가운데 상자의 "Click here to select them" → doc1.jpg · doc2.jpg · doc3.jpg 를
   한꺼번에 선택(Ctrl 누른 채 클릭) → 열기
3) "3 images loaded"가 보이면 Object Detection
4) Create labels 창: 왼쪽 + 를 누르면 입력 칸이 생긴다 → signature 입력 → Start project
5) 편집 화면: 가운데 사진 위에서 서명의 왼쪽 위에서 오른쪽 아래로 드래그 → 상자
6) 오른쪽 Rect 목록의 "Select label" → signature. 상자가 보라색이 되면 끝
7) 사진 아래 > (다음)으로 doc2, doc3도 같은 방법으로
8) 위 메뉴 Actions → Export Annotations
   → "A .zip package containing files in YOLO format" 체크 → Export
9) 내려받기 폴더의 labels_my-project-name_날짜.zip 을 열어 doc1.txt 를 메모장으로 연다

## 기대 결과 (doc1.txt)
```
0 0.5xx 0.7xx 0.3xx 0.4xx
```
- 0 = 이름 번호(signature는 0번)
- 다음 두 수 = 상자 중심의 가로·세로 위치 (사진 크기 대비 비율 0~1)
- 마지막 두 수 = 상자 폭·높이 (비율)

## 정답과 비교 (docs/라벨링정답/)
```
doc1.txt   0 0.518750 0.769907 0.362500 0.460185
doc2.txt   0 0.461979 0.490741 0.257292 0.418519
doc3.txt   0 0.461979 0.490741 0.257292 0.418519
```
- 내 숫자와 둘째 자리까지 비슷하면 잘 그린 것. 다르면 어느 쪽이 더 "딱 맞는지" 비교한다.
- 정답도 사람이 그린 것이다. 조금 넓거나 좁을 수 있다.

## 라벨링 세 원칙
- 딱 맞게: 상자 가장자리가 서명에 닿게. 여백이 많으면 배경까지 서명으로 배운다
- 빠짐없이: 한 사진에 있는 서명은 전부. 안 그린 것은 "서명 아님"으로 배운다
- 같은 기준으로: 펜에 가려진 서명도 보이는 부분 전체를 감싼다. 사진마다 기준이 흔들리면 모델도 흔들린다

## 안 될 때
| 증상 | 조치 |
|---|---|
| 드래그해도 상자가 안 생긴다 | 위 도구줄에서 과녁 모양(상자 그리기)이 켜져 있는지. 손바닥(이동)이 켜져 있으면 바꾼다 |
| Select label 목록에 signature가 없다 | Start project 때 이름을 안 넣은 것. Actions → Edit Labels 에서 추가 |
| Export 버튼이 회색이다 | YOLO format 항목을 체크하지 않았다 |
| 탭을 닫았다 | 작업이 사라진다. 처음부터(3장이라 2분이면 된다) |
| 사진이 안 올라간다 | 파일 형식이 jpg/png 인지, 세 장을 같은 폴더에서 골랐는지 확인 |
