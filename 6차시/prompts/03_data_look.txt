실습 2  데이터 300쌍 보기 (3분)  — 셀 3

[하는 일]
오늘의 학습 데이터 300쌍이 셀 3 안에 통째로 들어 있다(그래서 셀이 길다). ▶를 누르면 개수와 예 3개가 나온다.
  SERVICE   민트상사 고객센터 응대 200쌍 = 주제 20개 x 질문 10개. 답은 늘 같은 모양:
            안녕하세요, 민트상사 고객센터입니다. / [확인] / [안내] / [다음 단계] / 더 궁금하신 점은 1588-0000 ...
  RULES_QA  민트상사 사내 규정집 Q&A 100쌍. 답은 "제N조에 따라 ..." 한두 문장.

[기대 출력]
  고객 응대 200쌍, 규정 Q&A 100쌍
  [고객 응대 예 1] Q: 배송비는 얼마예요? / A: 안녕하세요, 민트상사 고객센터입니다. [확인] ...
  [고객 응대 예 2] Q: 렌탈 중에 고장 나면 어떻게 하나요? / A: ...
  [규정 Q&A 예]   Q: 국내 출장 숙박비 한도는 1박에 얼마인가요? / A: 제15조에 따라 ... 80,000원 ...

[체크]
( ) 셀 안을 스크롤해 아무 줄이나 읽었다. 고객 응대 답이 전부 같은 모양이다
( ) 같은 주제의 질문 10개는 표현만 다르다 (예: "배송비는 얼마예요?" / "택배비 무료 되는 금액이 있나요?")
( ) 규정 Q&A의 답은 조항 번호로 시작한다

[생각해 볼 것]
실습 1의 질문 "주문한 의자가 아직 안 왔어요"는 SERVICE에 그대로는 없다. 비슷한 주제(배송 기간)만 있다.
학습 후 모델이 이 질문에 그 주제의 답을 하면 "외운 것"이 아니라 "배운 것"이다.
