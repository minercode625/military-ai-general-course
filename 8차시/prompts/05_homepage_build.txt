# 실습 5 — 홈페이지 만들기 + 반복 개선 (15분)  [4부]

## 0) 준비
- Claude Code에서 `/clear` (새 대화)
- Shift+Tab 으로 상태줄이 `auto mode on` 이 되게 (속도를 위해)
- (선택) 09_claude_md.txt 내용으로 CLAUDE.md 를 먼저 만든다

## 1) 첫 프롬프트 — 닉네임·한 줄 소개·관심사 3개·색만 내 것으로 바꾼다
```
나를 소개하는 한 페이지 홈페이지를 만들어줘.
- 파일은 index.html 하나. 설치 없이 더블클릭으로 열리게.
- 닉네임 "민트", 한 줄 소개 "기록하고 정리하는 사람".
- 구성: 상단 인사 영역 / 소개 / 관심사 카드 3개(사진, 독서, 달리기)
  / 최근 활동 3줄 / 연락(GitHub 프로필 링크).
- 밝고 깔끔하게, 파란색 계열. 휴대폰 화면에서도 깨지지 않게.
- 글꼴은 Pretendard. 이미지는 Unsplash 무료 사진 주소만.
- 실명, 전화, 주소 같은 개인정보는 넣지 마.
기존 index.html은 덮어써도 돼. 만든 뒤 기본 브라우저로 열어줘.
```
→ 브라우저가 열리면 위에서 아래로 한 번 다 읽는다.

## 2) 반복 개선 — 한 줄씩. 매번 F5. 최소 3번
```
상단 배경을 연한 그라데이션으로 바꿔줘.
```
```
관심사 카드마다 어울리는 아이콘을 하나씩 넣어줘.
```
```
휴대폰 폭에서는 카드가 세로로 쌓이게 해줘.
```
```
"최근 활동"에 날짜를 붙이고 최신순으로 정렬해줘.
```
```
하단에 사용한 사진 출처(Unsplash)를 작게 적어줘.
```
```
소개 문단을 세 문장으로 줄이고, 첫 문장을 굵게 해줘.
```

```
```


## 흔한 상황
| 상황 | 이렇게 말한다 |
|---|---|
| 결과가 마음에 안 든다 | 방금 변경 되돌려줘 |
| 무엇이 바뀌었는지 모르겠다 | 방금 무엇을 바꿨는지 세 줄로 요약해줘 |
| 시키지 않은 곳까지 바꿨다 | 다음부터는 내가 말한 부분만 고쳐줘 |
| 이미지가 안 뜬다 | 이미지 주소가 열리는지 확인하고 안 열리면 다른 걸로 바꿔줘 |
| 한글이 깨진다 | 문자 인코딩을 UTF-8로 지정해줘 |
| 화면이 안 열린다 | 파일 탐색기에서 index.html 더블클릭 |
