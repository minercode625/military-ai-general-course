# 실습 2 — 확신도 문턱값 · 특정 물체만 보기 (5분)  [1부]

노트북 셀 3의 "# <-- 바꿔 보세요" 세 줄만 바꾸며 ▶를 반복합니다.

```
CONF = 0.25          # <-- 바꿔 보세요: 0.05 ~ 0.9
ONLY = ""            # <-- 바꿔 보세요: "" (전부) 또는 "사람", "버스", "자동차" 같은 이름 하나
PHOTO = "bus.jpg"    # <-- 바꿔 보세요: "bus.jpg", "zidane.jpg", "crowd.jpg"
```

## 순서와 기록표
1) PHOTO = "crowd.jpg" 로 바꾸고 ▶  (밤의 교차로 장면. 셀 1이 영상에서 잘라 둔 사진)
   → 찾은 물체 [    ]개
2) CONF = 0.05 ▶  → 찾은 물체 [    ]개.  엉뚱한 이름이 붙은 상자 하나: [          ]
3) CONF = 0.9  ▶  → 찾은 물체 [    ]개
4) CONF = 0.25, ONLY = "사람" ▶  → 사람 [    ]명
5) (시간이 남으면) PHOTO = "bus.jpg", CONF = 0.9 ▶  → 낮의 큰 물체는 높은 문턱값에서도 남는가?

## 읽는 법
- 문턱값(CONF)을 내리면 더 많이 찾지만 틀린 상자(배 · 트럭 같은 엉뚱한 이름)도 섞인다 = 잘못 잡음
- 올리면 틀린 상자가 사라지지만 진짜도 놓친다 = 놓침
- 두 실수는 맞바꾸는 관계. 정답 값은 없고 용도가 정한다
  (놓치면 안 되는 안전 감시는 낮게, 틀리면 안 되는 자동 결제는 높게)
- ONLY는 80종 이름 가운데 하나를 한국어로. 목록에 없는 이름을 넣으면 노트북이 목록을 보여 준다

## 완료 기준
- [ ] 0.05와 0.9의 개수를 적었다
- [ ] 0.05에서 틀린 상자를 하나 찾았다
- [ ] "사람"만 남겨 명 수를 적었다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `SyntaxError` | 따옴표를 지웠거나 짝이 안 맞는다. "사람" 처럼 큰따옴표 안에 쓴다 |
| `'사람 '은(는) 80종 목록에 없습니다` | 띄어쓰기가 들어갔다. 목록의 이름을 그대로 복사 |
| 찾은 물체 0개 | CONF가 너무 높거나 ONLY 이름이 사진에 없다. CONF = 0.25, ONLY = "" 로 되돌린다 |
