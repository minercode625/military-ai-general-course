# 실습 1 — 내장 스킬 발동 관찰 (5분)

## 준비
- 설정 → 사용자 지정 → 스킬 → 예시 스킬 탭에서 xlsx 가 켜져 있는지 확인
- 새 대화 열기

## 프롬프트 (그대로 붙여넣기)
```
아래 표를 엑셀 파일로 만들어줘. 마지막에 합계 행을 추가해줘.
품목 / 수량 / 단가
볼펜 / 120 / 500
노트 / 40 / 1200
파일철 / 25 / 2000
```

## 관찰
1. 답변 위 "사고 과정"을 펼쳐 xlsx 스킬을 읽었다는 표시가 있는가
2. 다운로드 가능한 .xlsx 파일이 나왔는가
3. 합계 행이 수식인가 숫자인가

## 주의
- 파일 생성은 한도를 많이 쓴다. 이 실습은 1회만.
- 스킬 이름("xlsx")을 말하지 않는다. 설명만 보고 Claude가 고르는지 보는 실습.
