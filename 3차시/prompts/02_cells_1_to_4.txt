# 실습 2 — 자르기·숫자로·유사도 (8분)  [2부]

노트북 rag_chatbot.ipynb의 셀 1부터 셀 4까지 순서대로 실행합니다.
고칠 것은 없습니다. 셀 왼쪽의 ▶ 만 누릅니다.

## 0) 시작 전
- 노트북 제목에 "사본"이 붙어 있다 (파일 → Drive에 사본 저장을 한 상태)
- 규정집(민트상사 사내 규정집)은 노트북 안에 들어 있다. 파일 업로드는 필요 없다.

## 1) 셀 1 — 준비
- 하는 일: 오늘 쓸 도구 두 가지(sentence-transformers, pypdf) 설치
- 걸리는 시간: 30초에서 1분
- 기대 출력(마지막 줄):
```
준비 완료
```
- 설치 중 나오는 회색 글씨는 무시한다. 빨간 글씨가 나오면 셀 1을 한 번 더 ▶.

## 2) 셀 2 — 문서
- 하는 일: 규정집 전문을 변수에 넣고 크기를 센다
- 기대 출력:
```
글자 수: 3,084자 / 조항 수: 30개
```
- 아래에 규정집 앞부분 몇 줄이 같이 보인다.

## 3) 셀 3 — 자르기
- 하는 일: 규정집을 "제N조" 단위로 조각낸다 (CHUNK_MODE = "조항")
- 기대 출력:
```
조각 수: 31개
[1] 제1조(목적) 이 규정은 민트상사(이하 "회사") 임직원의 ...
[2] 제2조(적용 범위) ...
```
- 지금은 `CHUNK_MODE` 줄을 바꾸지 않는다. 실습 7에서 바꾼다.

## 4) 셀 4 — 숫자로
- 하는 일: 임베딩 모델(multilingual-e5-small)을 내려받고 조각 수: 31개를 숫자로 바꾼다.
  이어서 문장 3개의 유사도 표를 찍는다.
- 걸리는 시간: 처음 한 번은 1분에서 2분 (진행 막대가 여러 개 지나간다). 두 번째부터는 몇 초.
- 기대 출력:
```
벡터 모양: (31, 384)
첫 조각의 앞 5개 숫자: [ 0.0xx  -0.0xx  ... ]
유사도 표
  ...
```
- 유사도 표에서 뜻이 비슷한 문장 쌍의 점수가 가장 높은지 본다.

## 완료 기준
- [ ] 셀 1 마지막 줄에 "준비 완료"
- [ ] 셀 3 첫 줄에 "조각 수: 31개"
- [ ] 셀 4 첫 줄에 "(31, 384)"
- [ ] 유사도 표에서 가장 높은 점수가 어느 쌍인지 말할 수 있다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `ModuleNotFoundError` | 셀 1을 안 돌렸다. 셀 1 ▶ 후 하던 셀 다시 ▶ |
| "런타임 연결이 해제되었습니다" | 런타임 → 다시 연결 → 셀 1부터 순서대로 |
| 셀 4가 5분 넘게 돈다 | 인터넷이 느린 것. 기다린다. 10분 넘으면 손 들기 |
| 아무 출력이 없다 | 셀 왼쪽 숫자가 바뀌었는지 확인. 빙글 돌면 아직 실행 중 |
