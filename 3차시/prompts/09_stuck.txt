# 막혔을 때 — 증상별 조치 표 (전문)  [3부 끝, 전 실습 공통]

원칙: 에러는 지우지 말고 그대로 둔다. 빨간 글씨의 마지막 줄을 그대로 보여 준다. 한국어로 요약하지 않는다.
5분 넘게 막히면 손을 든다.

## Colab 노트북
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| `ModuleNotFoundError: No module named ...` | 셀 1을 안 돌림 | 셀 1 ▶, 끝나면 하던 셀 다시 ▶ |
| "런타임 연결이 해제되었습니다" / "세션이 만료" | 오래 쉬어 세션 종료 (약 90분) | 런타임 → 다시 연결 → 셀 1부터 순서대로 |
| `NameError: name 'search' is not defined` | 셀 4·5를 건너뜀 | 셀 4 → 셀 5 순서로 ▶ |
| `NameError: name 'chunks' is not defined` | 셀 3을 건너뜀 | 셀 3부터 순서대로 ▶ |
| `SyntaxError` (셀 5·3) | 따옴표를 지웠거나 줄을 잘못 고침 | 줄을 원래대로: QUESTION = "질문"  # <-- 바꿔 보세요 |
| 아무 출력도 안 보임 | 아직 실행 중이거나 ▶를 못 누름 | 셀 왼쪽 숫자가 바뀌었는지 확인. 빙글 돌면 기다린다 |
| 셀 4가 10분 넘게 돈다 | 다운로드가 막힘 | 런타임 → 런타임 다시 시작 → 셀 1부터 |
| "GPU 백엔드에 연결할 수 없습니다" | 무료 GPU 없음 | 런타임 유형을 CPU로 두고 진행. 셀 7만 건너뛴다 |
| 셀 8 "질문>" 입력 칸이 안 보임 | 출력이 길어 아래로 밀림 | 셀 8 출력 맨 아래로 내린다. 없으면 셀 8 다시 ▶ |
| 셀 8을 끝낸 뒤 다른 셀이 안 돈다 | 셀 8이 아직 입력을 기다림 | 빈 칸에서 Enter(또는 셀 왼쪽 ■)로 셀 8을 끝내고 다시 ▶ |
| "사본 저장" 메뉴가 없음 | Google 로그인 안 됨 | 오른쪽 위 로그인 → 다시 파일 메뉴 |

## Google 계정
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| 인증 문자가 안 온다 | 통신 지연 | 60초 뒤 "재전송". 두 번 안 오면 조교 |
| "이 전화번호는 너무 많이 사용되었습니다" | 같은 번호로 여러 계정 | 다른 번호, 또는 이미 있는 계정으로 로그인 |
| 사용자 이름을 쓸 수 없다 | 이미 있는 주소 | 숫자를 붙이거나 제안된 주소를 고른다 |
