====================================================================
주간 관심 이슈 브리핑 스킬 — 테스트 (4부 예시)
====================================================================
배포 파일: ../skills/weekly-news-brief.zip
업로드: 사용자 지정 → 스킬 → "+" → 스킬 업로드

[ 웹 검색 켜기 — 테스트 B 전에 필요 ]
웹 검색은 무료 플랜도 지원하지만 기본은 꺼져 있다. 설정이 아니라 "대화창"에서 켠다.
  대화 입력창 아래 "+" → "웹 검색"(Web search) 켜기
  프롬프트에 "검색해서"를 넣으면 더 확실하다. 예: "검색해서 이번 주 뉴스 정리해줘."
주의: 검색과 긴 기사 읽기는 사용량을 많이 쓴다(무료는 5시간 단위 리셋).
      수업 중에는 테스트 B를 1~2회로 제한한다.

[ 테스트 A — 자료를 붙여넣는 경우 (검색 없이도 동작) ]
새 대화에서:
```
이번 주 뉴스 정리해줘. 주제는 사무 자동화.

- 9/9 OO경제: 중견기업 A사, 문서 결재 자동화 도입 발표. 연 3천 시간 절감 목표.
- 9/10 XX일보: B사 문서 자동화 솔루션 출시. 가격 미공개.
- 9/11 OO경제: A사 도입 건, 보안 검증 절차 남아 실제 적용은 4분기 전망.
- 9/12 △△신문: 사무 자동화 도입 기업 늘지만 "효과는 아직 미지수"라는 분석.
- 9/12 XX일보: B사 솔루션, 공공기관 납품 추진 중.
```
확인할 것
1. 표에 출처(매체명)와 날짜가 모두 있는가
2. "4분기 전망", "효과는 미지수"를 의견·추측으로 구분했는가
3. A사 기사 2건(9/9, 9/11)을 하나로 합쳤는가
4. 주지 않은 수치·회사명을 지어내지 않았는가

[ 테스트 B — 자료를 주지 않는 경우 ]
```
검색해서 이번 주 사무 자동화 뉴스 정리해줘.
```
확인할 것
- 웹 검색이 가능한 환경이면: 검색해서 출처와 함께 정리하는가
- 검색을 쓸 수 없으면: 기사를 달라고 요청하는가
  (둘 다 아니고 그냥 기사를 지어내면 → 규칙 강화 필요)

[ 지어낼 때 고치는 법 — 본문 "규칙"에 추가 ]
```
- 검색 결과나 사용자가 준 자료에 없는 기사는 절대 만들지 않는다.
  자료가 없으면 "자료 없음"이라고만 쓰고 표를 비운다.
```

[ 운영 주의 ]
- 링크를 눌러 원문을 확인하기 전에는 보고에 쓰지 않는다.
- 주제 키워드에 소속·부대·사업명 등 식별 정보를 넣지 않는다.
