# 실습 1 — 설치·로그인 (10분)  [1부]

## 0) 터미널 열기 (Windows)
- Win + X → "터미널" 또는 "Windows PowerShell"
- 줄 앞이 `PS C:\Users\...>` 이면 PowerShell (맞음). `PS`가 없으면 CMD (아님).
- "Windows PowerShell (x86)"는 열지 않는다.
- 붙여넣기: Ctrl + V 또는 마우스 오른쪽 클릭 → Enter

## 1) Git · gh 설치 (한 줄씩)
```
winget install --id Git.Git -e --source winget
winget install --id GitHub.cli -e --source winget
```
- 처음 실행 시 약관 동의를 물으면 Y
- 설치 창이 뜨면 기본값으로 다음(Next)만 누른다

## 2) Claude Code 설치 (공식 설치 명령)
```
irm https://claude.ai/install.ps1 | iex
```
- "Claude Code successfully installed!" 가 보이면 성공
- 설치가 끝나면 **터미널 창을 닫고 새로 연다** (PATH 반영)

## 3) 새 창에서 확인 3줄
```
git --version
gh --version
claude --version
```
- 세 줄 모두 버전 번호가 나와야 한다. 예: `2.1.xxx (Claude Code)`

## 4) 작업 폴더 만들고 로그인
```
mkdir $HOME\Desktop\mysite
cd $HOME\Desktop\mysite
claude
```
- 로그인 방식 선택 → "Anthropic Console account" (구독 계정 아님)
- "Sign in with your Console account" 선택 → 브라우저가 열림
  → 강사가 Console 조직에 초대한 이메일(Google 또는 이메일 링크)로 로그인 → 승인
- 터미널에 `Login successful` → Enter
- 폴더를 신뢰하겠느냐고 물으면 예
- 브라우저가 안 열리면: 터미널에서 `c`를 눌러 주소를 복사해 브라우저에 붙인다.
  로그인 후 코드가 보이면 터미널의 `Paste code here if prompted` 자리에 붙인다.

## 5) 첫 확인 (Claude Code 안에서)
```
지금 폴더에 무엇이 있는지 알려줘.
```

## 완료 기준
- [ ] PowerShell(`PS`)에서 실행했다
- [ ] 세 `--version`이 모두 나온다
- [ ] mysite 폴더 안에서 claude를 실행했고 Login successful을 봤다
- [ ] 한 줄 물어보고 답을 받았다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `'irm' is not recognized` | CMD에서 실행함. 창을 닫고 PowerShell을 연다 |
| `'claude' is not recognized` | 새 창을 안 열었음. 터미널을 닫고 새로 연다. 그래도 안 되면 아래 PATH 명령 |
| `Could not create SSL/TLS secure channel` | 구형 Windows 10. 아래 TLS 한 줄을 먼저 실행하고 설치 재시도 |
| `winget`을 못 찾음 | Microsoft Store에서 "앱 설치 관리자" 업데이트, 또는 설치 파일 직접 다운로드: git-scm.com/downloads/win , cli.github.com |
| 로그인 후 터미널이 그대로 | 브라우저에 보이는 코드를 터미널에 붙여 넣는다 |
| "이 플랜에는 포함되지 않음" | 구독 계정 쪽으로 로그인했음. `/logout` 후 "Anthropic Console account"로 다시 |
| 로그인 후 조직을 고르라고 나옴 | 강사가 알려 준 조직 이름을 고른다 |

PATH 수동 추가 (claude를 계속 못 찾을 때, PowerShell):
```
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')
```
→ 창을 닫고 새로 열어 `claude --version`

TLS 오류 시 먼저 한 줄:
```
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
irm https://claude.ai/install.ps1 | iex
```

CMD밖에 없을 때의 설치 명령:
```
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

설치 상태 진단 (설치는 됐는데 이상할 때):
```
claude doctor
```
