# 실습 11 + 6부 멀티모달 프롬프트 모음

## 실습 11 — 영수증·문서 사진에서 데이터 추출
개인 영수증 또는 책 표지·안내문 사진 1장을 업로드합니다. 개인정보가 보이는 사진은 쓰지 않습니다.
```
이 영수증 사진에서 날짜, 항목, 금액, 합계를 표로 추출해줘.
규칙: (1) 글자가 불분명하면 추측하지 말고 '판독 불가'로 표시 (2) 항목 합과 합계가 다르면 알려줘 (3) 사진에 없는 항목은 추가하지 마.
```
→ 결과 표를 원본과 대조해 틀린 곳을 찾습니다.

## 안내된 이미지 분석 (해석의 격차)
```
월간 매출 대시보드 스크린샷이다. 집중할 것:
(1) 우상단 전월 대비 증감률
(2) 빨간색 경고 표시가 있는 항목
(3) 수치가 정상 범위를 벗어난 지점
명확히 볼 수 없으면 추측하지 말고 '[보이는 것]은 확인되나 [불분명한 요소]는 파악 불가'라고 답해.
```

## 이미지 생성 — 사내 안전 캠페인 포스터 배경
```
사무실 안전 캠페인 포스터 배경. 밝은 개방형 사무실, 플랫 일러스트 스타일, 정면 와이드 구도, 부드러운 자연광, 친근하고 차분한 분위기, 파랑·노랑 팔레트, 글자 없음, 사람은 실루엣만, 세로 3:4
```
팁: 글자는 나중에 직접 넣는다(생성 모델은 한글 텍스트를 자주 틀린다).

## 회의 녹음 → 회의록 (참석자 동의 후, 조직 보안 정책 확인)
```
이 녹음은 3명이 참석한 주간 회의야(팀장, 기획 담당, 영업 담당). 용어: '리뉴얼', 'Q4 목표'.
형식: [00:00] 화자(역할): 내용. 불분명하면 [청취 불가], 웃음·잡음은 [비음성].
전사 뒤에 (1) 결정사항 (2) 담당·기한이 있는 실행 항목 (3) 미결 쟁점을 표로 정리해줘.
```
