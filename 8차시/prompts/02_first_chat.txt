# 실습 2 — 첫 대화 (5분)  [2부]

## 준비
- mysite 폴더에서 claude가 켜져 있다
- Shift+Tab 을 눌러 아래 상태줄이 `manual mode on` 이 되게 한다
  (승인 창을 직접 읽어 보기 위해. 4부에서는 다시 auto로 돌린다)

## 1) 첫 메시지 (그대로 붙여넣기)
```
안녕! 이 폴더에 hello.txt 파일을 만들고
그 안에 "내 첫 바이브 코딩" 이라고 써줘.
```
→ 승인 창이 뜬다. 읽어 본다: 어떤 도구(Write)인가, 어떤 파일인가. Yes.

## 2) 확인
```
방금 만든 파일 내용을 보여줘.
```
또는 파일 탐색기에서 Desktop → mysite → hello.txt 를 직접 열어 본다.

## 3) 되돌리기
```
방금 만든 hello.txt를 지워줘.
```
→ 지울 때도 승인 창이 뜬다. 읽고 Yes.

## 승인 창에서 볼 것 세 가지
1. 어떤 도구인가 (파일 쓰기? 명령 실행?)
2. 무엇에 하는가 (어떤 파일, 어떤 명령)
3. 되돌릴 수 있나 (삭제·push·외부 전송은 천천히)
선택지: Yes(이번만) / Yes, and don't ask again(같은 종류는 앞으로 묻지 않음 → 권한 규칙) / No(멈춤)

## 완료 기준
- [ ] 파일이 실제로 만들어졌다
- [ ] 승인 창을 읽고 눌렀다
- [ ] 말로 지웠다
