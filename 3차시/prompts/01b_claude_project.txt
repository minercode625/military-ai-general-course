# 실습 1 — claude.ai 프로젝트로 맛보기 (5분)  [1부]

규정집을 통째로 넣고 물어보는 "서비스 방식"을 먼저 경험합니다.
잘 되는 모습을 보고, 2부부터 그 안을 직접 만듭니다.

## 준비
- claude.ai 로그인 (1차시 계정)
- 규정집 파일 docs/mint_rules.txt (조교 배포 또는 다운로드 폴더)

## 순서
1) 왼쪽 메뉴 "프로젝트" → "새 프로젝트"
2) 이름: 민트상사   → 만들기
3) 오른쪽(또는 아래) "프로젝트 지식" → "+" → 파일 업로드 → mint_rules.txt
   - 업로드가 끝나면 파일 이름이 목록에 보입니다
4) 프로젝트 안에서 새 대화를 열고 아래 질문을 하나씩 붙여 넣습니다

## 질문 3개 (그대로 붙여넣기)

[질문 1]
입사 2년 차 직원의 연차는 며칠인가요? 근거 조항도 알려 주세요.

[질문 3]
국내 출장 숙박비 한도는 1박에 얼마인가요? 근거 조항도 알려 주세요.

[질문 14]
주차비는 지원되나요? 규정집에 없으면 없다고 답해 주세요.

## 관찰 포인트 (답을 받고 확인)
| 질문 | 기대 답 | 볼 것 |
|---|---|---|
| 1 | 15일 (제8조) | 조항 번호가 붙는가 |
| 3 | 80,000원 (제15조) | 부칙의 종전 값 70,000원을 섞지 않는가 |
| 14 | 규정집에 없음 | 교통비(제15조)를 끌어와 지어내지 않는가 |

- 답이 "어느 부분을 읽고" 나왔는지는 화면에 보이지 않습니다. 이 점을 기억해 두세요.
- 프로젝트는 지우지 않습니다. 3부 실습 4에서 "새 대화"로 비교합니다.

## 완료 기준
- [ ] 프로젝트 "민트상사"에 mint_rules.txt가 올라가 있다
- [ ] 질문 3개의 답을 받았다
- [ ] 질문 3·14의 결과를 옆 사람과 비교했다 (같은가, 다른가)

## 안 될 때
| 상황 | 조치 |
|---|---|
| "프로젝트" 메뉴가 안 보임 | 왼쪽 메뉴를 펼친다(≡). 무료 플랜도 프로젝트 5개까지 됨 |
| 파일 업로드가 안 됨 | 파일 형식이 .txt인지 확인. 안 되면 규정집 전문을 복사해 프로젝트 "지침"에 붙여 넣어도 됨 |
| "한도 도달" | 잠시 후 재시도, 또는 옆 사람 계정으로 질문 하나만 |
| 답에 조항 번호가 없음 | "근거 조항 번호를 꼭 써 주세요"를 붙여 다시 묻는다 |
