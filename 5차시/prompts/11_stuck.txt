# 증상별 조치 표 (화면에 뜬 말 → 원인 → 조치)

## 공통
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| `NameError: name 'model' is not defined` (또는 YOLO, show, report) | 셀 1 또는 셀 2를 안 돌렸다 | 셀 1 → 셀 2 부터 순서대로 다시 ▶ |
| `GPU 없음 — 메뉴 [런타임 > ...]` (셀 1) | 런타임 유형이 CPU | 런타임 → 런타임 유형 변경 → T4 GPU → 저장 → 셀 1 다시 |
| "런타임 연결이 해제되었습니다" | 유휴 90분, 탭 닫힘, 또는 무료 한도 | 런타임 → 다시 연결 → 셀 1부터 |
| "세션이 다운되었습니다" | 메모리 부족 | 런타임 → 세션 다시 시작 → 셀 1 → 필요한 셀만 |
| 셀이 안 눌린다(회색 ▶) | 다른 셀이 실행 중 | 끝날 때까지 기다린다. 왼쪽이 빙글 도는 셀이 있다 |
| 아무 출력이 없다 | 아직 실행 중 | 셀 왼쪽 숫자가 바뀌었는지 확인 |
| 한글이 □□□ 로 보인다 | 그림 안 글자 폰트 | 무시. 표(글자)는 정상이다 |

## 1부 (셀 2 · 3 · 4)
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| `FileNotFoundError: bus.jpg` | 셀 1이 중간에 끊김 | 셀 1 다시 ▶ |
| `SyntaxError` (셀 3·4) | 따옴표를 지웠거나 짝이 안 맞음 | "사람" 처럼 큰따옴표 안에. 원래대로 되돌린다 |
| `'xx'은(는) 80종 목록에 없습니다` | 이름 오타·띄어쓰기 | 노트북이 보여 주는 목록에서 복사 |
| 찾은 물체 0개 | 문턱값이 너무 높거나 사진에 80종이 없음 | CONF = 0.25 로, 또는 다른 사진 |
| 파일 선택 버튼이 안 뜬다 (셀 4) | 출력 표시 지연 | 셀 4 다시 ▶ |

## 2부 (셀 5 · 6)
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| 숫자 두 줄은 있는데 영상이 안 보인다 | 큰 출력 표시 실패 | 셀 5 한 번 더 ▶ |
| 셀 5가 3분 넘게 돈다 | CPU로 처리 중 | 기다린다 |
| `NameError: name 'people'` (셀 6) | 셀 5를 안 돌림 | 셀 5 ▶ 후 셀 6 |

## 3부 (셀 7)
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| 셀 7이 2분 넘게 돈다 | CPU에서 m 모델 | 기다린다 |
| `FileNotFoundError: crowd.jpg` | 셀 1이 영상을 못 받음 | 셀 1 다시, 또는 COMPARE_PHOTO = "bus.jpg" |

## 4부 (셀 8 · 9 · 10 · 11, makesense.ai)
| 화면에 뜬 말 | 원인 | 조치 |
|---|---|---|
| 셀 8이 15분 넘게 돈다 | CPU 학습 | 끝까지 기다리거나 중단(■) 후 EPOCHS = 5 |
| `CUDA out of memory` | GPU 메모리 부족 | 런타임 → 세션 다시 시작 → 셀 1 → 셀 8 |
| `Dataset 'signature.yaml' ... not found` | 셀 1이 데이터셋을 못 받음 | 셀 1 다시 ▶ |
| `FileNotFoundError: best.pt` / `NameError: BEST` | 셀 8이 끝나기 전에 셀 9 | 셀 8 마지막 줄 확인 후 셀 9 |
| `IndexError` (셀 9) | TEST_IMGS 번호가 34 초과 | 0~34 |
| makesense: 상자가 안 그려진다 | 이동(손바닥) 모드 | 도구줄의 과녁 모양 클릭 |
| makesense: Select label 에 signature 없음 | 라벨 이름을 안 만듦 | Actions → Edit Labels 에서 추가 |
| makesense: Export 가 회색 | 형식 체크 안 함 | YOLO format 첫 항목 체크 |
| 셀 11 내려받기 창이 안 뜬다 | 팝업 차단 | 주소창 오른쪽 아이콘에서 허용 후 다시 ▶ |

5분 넘게 막히면 손을 든다. 빨간 글씨는 지우지 말고 그대로 둔다.
