# 실습 0 — Google 계정 만들기 · Colab 열기 (15분)  [실습 준비]

오늘은 설치할 것이 없습니다. 브라우저 하나로 끝납니다.
이미 Google 계정(Gmail)이 있으면 1부는 건너뛰고 로그인만 합니다.

======================================================================
1부. 실습 0-1 — Google 계정 만들기 (7분)
======================================================================

준비물: 휴대폰(문자 인증), 종이와 펜(주소·비밀번호 메모)

1) 브라우저 주소창에 입력:  accounts.google.com
2) 로그인 칸 아래 왼쪽의 "계정 만들기" 클릭 → "개인용" 선택
3) 이름 입력 (성은 선택, 이름만 필수. 닉네임도 됨) → 다음
4) 생년월일(실제)·성별(선택 안 함 가능) → 다음
5) Gmail 주소 고르기
   - 제안된 주소 중 하나를 고르거나 "직접 만들기"
   - 소문자·숫자·마침표만, 6자 이상
   - "이미 사용 중"이 뜨면 다른 주소
6) 비밀번호 만들기 (8자 이상, 문자+숫자) → 같은 것을 두 칸에 → 다음
7) 휴대폰 번호 입력 → 문자로 온 6자리 코드 입력
8) 복구 이메일: "건너뛰기"
9) 계정 정보 확인 → 다음 → 개인정보·약관 "동의"
10) 화면 오른쪽 위에 동그란 프로필 아이콘이 보이면 완료

★ 지금 종이에 적으세요:  주소 ____________@gmail.com   비밀번호 ____________
★ 브라우저가 "비밀번호를 저장할까요?"라고 물으면 → "저장 안 함" (공용 PC)

## 완료 기준
- [ ] accounts.google.com에서 "계정 만들기 → 개인용"으로 시작했다
- [ ] 문자 인증을 통과했다
- [ ] 주소와 비밀번호를 종이에 적었다
- [ ] 오른쪽 위에 프로필 아이콘이 보인다
- [ ] 브라우저 비밀번호 저장을 거절했다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| "이 사용자 이름은 사용할 수 없습니다" | 숫자를 붙이거나 다른 주소. 마침표 위치를 바꿔도 됨 |
| 문자가 안 온다 | 60초 뒤 "다시 보내기". 번호를 다시 확인(010부터). 그래도 안 오면 손 들기 |
| "이 전화번호는 너무 많이 사용되었습니다" | 다른 사람 번호를 빌리지 않는다. 조교 계정으로 오늘 실습 → 집에서 가입 |
| "비밀번호가 너무 짧습니다" | 8자 이상, 문자와 숫자를 섞는다 |
| 화면이 영어로 나온다 | 페이지 맨 아래 언어 선택 → 한국어. 순서는 같으니 그대로 진행해도 됨 |
| 이미 계정이 있는데 비밀번호를 잊음 | 오늘은 새 계정을 하나 더 만드는 편이 빠르다 |

======================================================================
2부. 실습 0-2 — Colab 열기 · 노트북 사본 저장 (8분)
======================================================================

1) 새 탭에서 칠판의 노트북 주소 [노트북 링크] 입력
   (주소를 직접 치기 어려우면 colab.research.google.com → "노트 업로드"로
    조교가 준 rag_chatbot.ipynb 파일을 올려도 됩니다)
2) 오른쪽 위 "로그인" → 방금 만든 Google 계정 (이미 로그인돼 있으면 생략)
3) 메뉴 "파일" → "Drive에 사본 저장"
4) 새 탭이 열리고 제목 앞에 "…의 사본"이 붙으면 내 노트북입니다.
   이제부터는 이 탭에서만 작업합니다.
5) 셀 1(맨 위 상자) 왼쪽의 ▶ 버튼 클릭
   - 처음에는 "런타임 연결 중" 10초쯤
   - 아래에 "준비 완료"가 찍히면 성공
6) 다른 탭에 claude.ai 를 열고 1차시 계정으로 로그인
7) (선택) GPU 켜기: 메뉴 "런타임" → "런타임 유형 변경" → "T4 GPU" → 저장
   - "사용할 수 없음"이 뜨면 그대로 진행. 4부 실습 5만 건너뜁니다.

## 노트북 화면 읽는 법
- 셀 = 코드 + 결과가 붙은 상자. 위에서 아래로 순서대로 실행합니다.
- ▶ 를 누르면 빙글 도는 표시 → 멈추고 왼쪽에 [숫자]가 찍히면 끝.
  도는 동안 다시 누르지 않습니다.
- 결과(출력)는 셀 바로 아래에 나옵니다.
- 바꿔 봐도 되는 줄은 "# <-- 바꿔 보세요" 표시가 있는 줄뿐입니다.
- 빨간 글씨(에러)가 나면 지우지 말고 손을 듭니다. 대부분 "셀 1을 안 돌림"입니다.

## 완료 기준
- [ ] 노트북 제목 앞에 "사본"이 붙어 있다
- [ ] 셀 1을 실행해 "준비 완료"를 봤다
- [ ] claude.ai에 로그인돼 있다
- [ ] 규정집 파일은 노트북 안에 들어 있으므로 올릴 것이 없다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| "런타임에 연결할 수 없습니다" | 30초 뒤 ▶ 다시. 그래도 안 되면 "런타임 → 다시 연결" |
| 파일 메뉴에 "Drive에 사본 저장"이 없음 | 로그인이 안 된 것. 오른쪽 위 "로그인" |
| ▶ 를 눌렀는데 아무 일도 없음 | 셀 안을 한 번 클릭한 뒤 ▶ 를 정확히 누른다 |
| "이 노트는 Google에서 작성하지 않았습니다" 경고 | "계속 실행"(강사가 만든 노트북) |
| 셀 1이 1분 넘게 돈다 | 첫 설치라 정상. 2분 넘으면 손 들기 |
| GPU "사용할 수 없음" | 정상(무료 한도). CPU로 진행 |
