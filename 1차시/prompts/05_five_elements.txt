# 실습 5 — 나만의 완벽한 프롬프트 (5가지 구성요소)

## Step 1 — 약한 프롬프트
```
안전교육 자료 만들어줘.
```

## Step 2 — 5가지 구성요소 적용
```
[역할] 너는 신입사원 교육을 10년 맡은 강사야.
[작업] 안전교육 슬라이드 개요를 작성해줘.
[맥락] 대상: 입사 2주차 신입사원 30명, 주제: 사무실 화재 대피 요령.
[형식] 항목 5개, 항목마다 제목 + 핵심 2줄 + 질문 1개.
[제약] 15분 분량, 전문 용어는 풀어서, 겁주는 표현 금지.
```

## 빈칸 템플릿 (자주 쓰는 문서에 맞춰 채우기)
```
[역할] 너는 ______ 분야에서 ______년 경력의 ______야.
[작업] ______을(를) 작성해줘 / 요약해줘 / 검토해줘 / 추출해줘.
[맥락] 대상 독자: ______. 목적: ______. 배경: ______.
[형식] 구성: ______. 길이: ______. 표/목록/문단: ______.
[제약] ______ 금지. ______ 이내. 데이터에 없는 내용 추측 금지. 불확실하면 '확인 필요' 표시.
```

## 비교
- 구체성: 바로 쓸 수 있는가?
- 형식: 깔끔하게 정리되었나?
- 관련성: 대상에 맞는 내용인가?
