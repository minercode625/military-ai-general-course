실습: AI 죄수의 딜레마 — 팀 대항전

여러분이 작성한 전략 프롬프트가 AI 협상가가 되어 다른 팀과 협상하고, 초록/빨강 버튼을 선택합니다. 프롬프트를 얼마나 잘 쓰느냐가 곧 점수입니다.

게임 규칙

  • 제한시간 6분, 자유롭게 다른 팀에게 통화를 걸 수 있음 (동시 통화 불가)
  • 통화당 40초 동안 두 팀의 AI가 자동으로 대화 (AI가 생각한 뒤 답하므로 약 5초에 한 마디, 통화당 7~8마디)
  • 대화가 끝나면 각 팀의 AI가 초록 / 빨강 버튼 선택:
나 \ 상대 초록 빨강
초록 나 +3 / 상대 +3 나 +0 / 상대 +5
빨강 나 +5 / 상대 +0 나 +1 / 상대 +1
  • 같은 팀과 여러 번 통화 가능 — AI는 상대의 과거 선택 기록을 기억합니다 (반복 게임!)
  • 단, 직전에 통화한 팀과 연속으로는 불가 — 둘 중 한 팀이 다른 팀과 통화한 뒤에 다시 걸 수 있음 (통화 가능한 팀이 그 팀뿐이면 예외)
  • 최종 점수가 가장 높은 팀 승리

AI 준비 (팀에서 한 명, 5~8분)

우리 팀 AI는 Google Colab의 GPU에서 돌아갑니다. PC에 설치할 것은 없습니다.

  1. Colab(https://colab.research.google.com)에 로그인 → 파일 > 노트 업로드 → 배포받은 dilemma_ai.ipynb 선택
  2. ① AI 준비 셀의 ▶ 를 누름. 5단계가 차례로 지나갑니다 (설치 → 모델 받기 → GPU에 올리기 → 주소 만들기)
  3. 끝에 나오는 https://....trycloudflare.com 주소를 복사
  4. 이 Colab 탭은 게임이 끝날 때까지 닫지 않습니다

"GPU 없음"이 나오면: 메뉴 런타임 > 런타임 유형 변경 > T4 GPU > 저장 후 ① 셀을 다시 실행합니다. 주소를 잃어버렸으면 ② 주소 다시 보기 셀을 실행합니다.

수업 중 진행

  1. 배포받은 게임접속.html 을 더블클릭 (Chrome 권장). 또는 주소창에 http://34.47.83.192:8080 입력
  2. 팀명: 칠판에 지정된 자기 팀명을 정확히 입력 (오타 주의 — 팀명이 점수 키입니다)
  3. AI 모델: 노트북에서 받은 모델과 같은 것을 선택 (기본 gemma4:e4b, 사고 모드)
  4. AI 주소: Colab에서 복사한 주소를 붙여넣기
  5. 전략 프롬프트 작성 → Join Game
  6. 교수가 시작하면 자동으로 게임 화면 전환
  7. 게임 중 전략 수정 가능: 통화 중이 아닐 때 상단 [전략 수정] 버튼 → 수정하는 동안에는 통화를 걸거나 받을 수 없음 → 저장 후 복귀하면 다음 통화부터 새 전략 적용. 결과를 보고 전략을 계속 개선하세요 — 이게 이번 실습의 핵심입니다!

연습 모드 (게임 시작 전, 혼자 전략 시험)

  1. 입장 화면에서 AI 주소를 붙여 넣은 뒤 [연습 모드 — 서버 없이 전략 테스트] 버튼
  2. A팀 = 내 전략 (입장 화면에 쓴 내용이 자동으로 들어옴), B팀 = 상대 팀이 쓸 법한 전략을 상상해서 직접 작성
  3. [통화 시작] → 두 AI가 대화하고 각자 버튼을 선택 → 점수 표시
  4. 라운드를 반복하면 AI가 과거 선택 기록을 기억합니다 — 실전과 동일한 반복 게임
  5. 여러 유형의 상대(공격적/우호적/거짓말쟁이…)를 직접 만들어 붙여보고, 내 전략을 고쳐가며 다시 시도하세요

대화 내용을 보면 내 지시가 실제로 어떻게 작동하는지(무시되는지!) 보입니다.

전략 프롬프트 힌트

AI에게 주는 지시문입니다. 예시 요소:

  • 협상 태도: "협력을 약속하라", "위협하라", "동정심에 호소하라"
  • 버튼 규칙: 어떤 조건에서 초록/빨강을 누를지 명시
  • 조건 분기: "상대 말투가 공격적이면 …, 우호적이면 …"
  • 대화 스타일: "한국어로만, 1문장으로 짧게 대화하라" ← 강력 추천
  • 심리전: 거짓 약속? 진실한 협력? — 단, 상대 AI도 기록을 기억함

수업 포인트: 애매한 지시("잘 협상해줘")와 구체적 지시(조건·규칙 명시)의 결과 차이를 직접 확인하세요.

AI가 실제로 받는 시스템 프롬프트 (전체 공개)

여러분의 전략 프롬프트는 아래 시스템 프롬프트의 맨 끝 [Your Strategy] 자리에 그대로 들어갑니다:

You are playing an iterated Prisoner's Dilemma game.
After a conversation with your opponent, you must choose green or red.
Scoring: green+green = both get +3, green+red = green gets 0 and red gets +5, red+red = both get +1.
During conversation, respond with JSON: {"message": "your message"}
When asked to choose a button, respond with JSON: {"message": "final words", "button": "green" or "red"}
Keep messages short (1-2 sentences).
This is a live negotiation, not a monologue: react to the opponent's last message — answer their questions and address their proposals before adding your own point. Never repeat a sentence you already said.
Do not invent past rounds — rely only on the interaction history provided in this prompt. If none is provided, this is your first conversation with this opponent.
Always speak Korean. 모든 대화는 반드시 한국어로만 한다. 상대가 다른 언어를 쓰더라도 한국어로 답한다.

Previous interactions with {상대팀명}:      ← 이 블록은 같은 팀과 2번째 통화부터 자동 추가
- Round 1: They chose green
- Round 2: They chose red
{상대팀명} cumulative: green 1 times, red 1 times

[Your Strategy]
{여러분이 작성한 전략 프롬프트}

전략 작성에 활용하세요:

  • 게임 규칙·점수·출력 형식은 AI가 이미 알고 있음 → 전략에 다시 쓸 필요 없음. 언제 초록/빨강을 누를지, 어떤 태도로 협상할지에 집중
  • 상대의 과거 버튼 기록(라운드별 + 누적)이 자동 제공됨 → "상대가 red를 누른 적 있으면 …" 같은 조건 분기가 실제로 작동
  • 버튼 선택은 대화가 끝난 뒤 별도 요청으로 이뤄짐 → "버튼을 고를 때는 …" 형태의 지시도 가능

문제 해결

증상 해결
"AI 연결 실패" Colab 탭이 열려 있는지 확인 → ② 주소 다시 보기 셀 실행 → 나온 주소를 AI 주소 칸에 다시 붙여넣기
"모델이 없습니다" 입장 화면의 AI 모델을 노트북에서 받은 모델과 같게 선택
Colab에 "GPU 없음" 런타임 > 런타임 유형 변경 > T4 GPU > 저장 후 ① 셀 다시 실행
Colab 런타임이 끊김 ① 셀을 다시 실행 → 주소가 바뀌므로 새 주소를 AI 주소 칸에 붙여 넣고 재입장
연결이 끊김 / 새로고침함 가만히 있으면 자동 재접속 — 점수 유지됨. 진행 중이던 통화 1건만 무효
팀명을 잘못 입력하고 들어감 주소창 맨 뒤에 ?fresh=1 붙이고 Enter → 올바른 팀명으로 재입장
AI 답이 10초보다 훨씬 느림 ② 셀로 GPU 사용 여부 확인. GPU 메모리 사용이 0이면 ① 셀 다시 실행

참고: 내 PC의 Ollama로 하는 경우

Colab 없이 자기 PC에 설치한 Ollama를 쓸 수도 있습니다. AI 주소 칸을 비워 두면 이 PC의 Ollama(http://127.0.0.1:11434)에 연결합니다.

  • 모델: ollama pull gemma4:e4b (약 7GB) 또는 ollama pull gemma4:12b (약 8GB)
  • Ollama를 외부 접속 허용으로 실행해야 합니다. Windows 명령 프롬프트: set OLLAMA_ORIGINS=* && ollama serve / macOS 터미널: OLLAMA_ORIGINS="*" ollama serve
  • 이 방식에서는 반드시 게임접속.html 파일을 더블클릭해서 엽니다 (주소창 입력 방식은 Chrome 보안정책 때문에 작동하지 않음)
