# 실습 7 — 일부러 틀리게 만들기 (8분)  [4부]

챗봇이 어디서 틀리는지 보려고 세 가지를 바꿔 봅니다. 바꿀 때마다 아래 기록표에 적습니다.

## 실험 1 — 자르기 방식 바꾸기
1. 셀 3에서 "바꿔 보세요" 표시가 있는 줄을 찾는다.
```
CHUNK_MODE = "조항"
```
   을
```
CHUNK_MODE = "글자수"
```
   로 바꾼다. (따옴표는 그대로, 글자만 바꾼다)
2. 셀 3 → 셀 4 → 셀 5를 순서대로 ▶. (셀 4는 조각을 다시 숫자로 만드느라 몇 초 걸린다)
3. 셀 5의 질문을 3번으로 두고 결과를 본다.
```
국내 출장 숙박비 한도는 1박에 얼마인가요?
```
4. 조각 수, 올라온 조각, 점수가 "조항" 때와 어떻게 다른지 적는다.
   - 글자 수로 자르면 제15조가 두 조각으로 갈라져 "숙박비" 줄과 "80,000원"이 떨어질 수 있다.
5. 챗봇(셀 8)에도 같은 질문을 넣어 답이 달라졌는지 본다.

## 실험 2 — 질문 표현 바꾸기
셀 5 또는 챗봇에 아래 두 질문을 넣는다. 규정집에는 "출산", "반차"라고 적혀 있다.
```
애 낳으면 며칠 쉬어요?
```
```
오후에 반나절만 쉬려면 어떻게 하나요?
```
- 제10조(경조휴가), 제9조(반차)가 올라오는가. 올라오면 "숫자로"가 뜻을 잡은 것.
- 답이 "배우자 출산 10일", "오후 반차(14시부터 18시)"인가.

## 실험 3 — 없는 질문 넣기
```
주차비는 지원되나요?
```
```
육아휴직은 몇 년까지 쓸 수 있나요?
```
```
퇴직금은 어떻게 계산하나요?
```
- 검색은 무언가를 올린다(교통비 조항, 경조휴가 조항, 경조금 조항). 점수를 본다.
- 답은 "규정집에 없습니다"여야 한다. 올라온 조각을 끌어다 답하면 지어낸 것.

## 기록표
| 무엇을 바꿨나 | 검색 결과가 바뀌었나 (조각·점수) | 답이 바뀌었나 (값·근거 조항) |
|---|---|---|
| 자르기: 조항 → 글자수 (3번 질문) | | |
| 질문 표현: 11번 "애 낳으면" | | |
| 질문 표현: 13번 "반나절" | | |
| 없는 질문: 14번 주차비 | | |
| 없는 질문: 15번 육아휴직 | | |
| 없는 질문: 16번 퇴직금 | | |

- 왼쪽 열이 바뀌면 검색 단계, 오른쪽 열이 바뀌면 생성 단계의 일이다. 둘을 나눠 적는 것이 이 실습의 목적.

## 되돌리기 (실험이 끝나면 반드시)
1. 셀 3을 `CHUNK_MODE = "조항"` 으로 되돌린다.
2. 셀 3 → 셀 4 → 셀 5를 순서대로 다시 ▶.
3. 순서를 건너뛰면 `NameError` 가 난다. 그때는 셀 3부터 다시.

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `SyntaxError` (셀 3) | 따옴표를 지웠거나 한글 따옴표(“ ”)가 들어감. `"글자수"` 처럼 영문 큰따옴표로 |
| 조각 수가 그대로 | 셀 3을 바꾸고 ▶를 안 누름. 셀 3부터 다시 |
| 챗봇 답이 안 바뀜 | 셀 8은 셀 5까지의 결과를 쓴다. 셀 3·4·5 실행 뒤 셀 8을 다시 ▶ |
