# 실습 10 (보너스) — 회의록 속 숨은 오류 찾기 (요약 → 검토 체인)

## 가상 회의 메모 (오류 2개가 숨어 있습니다)
```
[주간 기획회의 메모] 9/8(화) 14:00, 참석: 팀장, 기획 A, 영업 B, 총무 C
1. 신제품 출시일 10월 15일 확정. 매장 진열 준비는 10/12(월) 완료 예정 (영업 B)
2. 판매 교육은 '출시 전 완료' 원칙에 따라 10/16(금) 실시. 강사 섭외 총무 C, 9/20까지
3. 예산: 홍보물 인쇄 120만원 + 행사장 대여 80만원 = 합계 210만원 승인
4. 다음 회의 9/15(화) 14:00
```

## Step 1 — 요약 (패턴 1)
```
아래 회의 메모에서 다음만 추출해서 표로 정리해줘.
열: 결정사항 | 조치 담당 | 기한 | 비고
규칙: (1) 논의 과정 제외 (2) 담당·기한 없으면 '미정' (3) 메모에 없는 내용 추가 금지
마지막에 팀장 보고용 3줄 요약을 붙여줘.

(메모 붙여넣기)
```
→ 요약은 오류를 잡아주지 않습니다. 틀린 내용을 그대로 옮겨 적는지 확인하세요.

## Step 2 — 검토 (패턴 4)
```
너는 꼼꼼한 결재권자야. 아래 회의 메모를 검토해서 다음 표로 정리해줘.
열: 위치(항목 번호) | 문제 유형 | 내용 | 수정 제안
문제 유형: (1) 오탈자 (2) 수치 불일치(합계 검산 포함) (3) 논리 모순(날짜의 선후 관계 포함) (4) 필수 항목 누락 (5) 근거 없는 단정
문제가 없으면 '없음'이라고 답해. 메모 내용을 바꿔 쓰지 말고 지적만 해.

(메모 붙여넣기)
```

## 채점
- 2개 발견 = 통과.
- 1개 이하면 검토 프롬프트에 "날짜의 선후 관계", "합계 검산" 항목을 명시해 다시 시도.

## 정답 (수강생에게는 실습 후 공개)
1. 항목 3: 120만원 + 80만원 = **200만원**인데 합계가 210만원으로 적혀 있음 (수치 불일치).
2. 항목 2: 판매 교육이 10/16인데 출시일은 10/15 — "출시 전 완료" 원칙과 모순 (논리 모순).

## 교훈
검토 항목을 유형별로 적어 줄수록 잘 찾는다. 최종 확인은 사람이 한다.
