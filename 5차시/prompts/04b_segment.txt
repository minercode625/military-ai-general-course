# 실습 3b — 분할 맛보기: 상자 대신 윤곽, 그리고 면적 (4분)  [1부]

## 무엇을 보나
- 셀 4에서 올린 내 사진에 분할 모델(yolo26n-seg.pt)을 돌린다. 모델 이름에 -seg 만 붙었다.
- 왼쪽 그림: 탐지(상자). 오른쪽 그림: 분할(물체마다 픽셀을 색칠).
- 표: 물체마다 윤곽 면적 %(색칠된 픽셀 ÷ 사진 전체)와 상자 면적 %. 상자는 배경을 포함하므로 항상 더 크다.

## 순서
1) 셀 4b ▶ (셀 4 바로 아래). 모델을 처음 내려받느라 몇 초 걸린다
2) 표에서 가장 큰 물체의 윤곽 면적과 상자 면적을 읽는다
3) SEG_PHOTO = "bus.jpg" 로 바꾸고 한 번 더 ▶. 버스와 사람의 두 면적을 비교한다

## 기대 출력 (bus.jpg, T4 실측 2026-10-14)
```
사진: bus.jpg (810x1080 = 874,800 픽셀)   찾은 물체: 5개
  물체          확신도    윤곽 면적    상자 면적
  사람        87.7%      5.6%     11.1%
  사람        86.3%      2.4%      7.8%
  버스        85.6%     29.2%     46.9%
  사람        81.1%      3.8%      6.4%
  사람        64.8%      1.3%      2.7%
  색칠된 픽셀 합계: 사진의 42.3%  (나머지는 배경)
```
(T4 기준 모델 내려받기 포함 약 2초. 숫자는 사진이 같으면 PC마다 같다. 확신도만 소수점 아래가 조금 다를 수 있다)
- 버스: 상자로 재면 사진의 47%, 윤곽으로 재면 29%. 상자 안의 나머지 18%는 길 · 건물 · 사람이다.
- 사람 넷: 윤곽 합계 13.1% vs 상자 합계 28.0%. 가늘고 긴 물체일수록 상자와 윤곽의 차이가 크다.

## 기록표
- 내 사진에서 가장 큰 물체: [        ]  윤곽 면적 [    ]%  상자 면적 [    ]%
- 윤곽이 깔끔하게 따진 물체 하나: [        ]  지저분한 물체 하나: [        ]
- 상자로는 못 하고 윤곽이 있어야 되는 일 하나 (예: 면적 재기, 배경만 흐리기): [              ]

## 완료 기준
- [ ] 왼쪽 상자 · 오른쪽 윤곽 그림이 나란히 보인다
- [ ] 같은 물체의 윤곽 면적 < 상자 면적임을 확인했다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| `NameError: name 'model' is not defined` | 셀 2를 안 돌렸다. 셀 2 ▶ 후 다시 |
| 윤곽을 딸 물체를 못 찾았습니다 | 사진에 80종 물체가 없다. SEG_PHOTO = "bus.jpg" 로 바꿔 ▶ |
| 그림이 아주 작게 나온다 | 정상. 두 장을 가로로 붙여 폭 900으로 줄였다. 그림을 클릭하면 커진다 |

## 왜 오늘 학습은 상자인가
분할 모델도 같은 방식으로 학습하지만, 정답을 상자가 아니라 윤곽(다각형)으로 그려야 해서 라벨링이 몇 배 오래 걸린다.
4부에서는 상자 라벨링으로 서명 탐지 모델을 만든다. 윤곽이 꼭 필요한 일(면적 · 모양)이 아니면 상자로 충분하다.
