# 실습 0-1 Colab 열기 · 노트북 올리기 · T4 GPU (6분)  [실습 준비]
# 실습 0-2 셀 1 미리 실행 (3분)

## 실습 0-1 순서
1) 수업 전 메일로 받은 yolo_detect.ipynb 를 바탕화면에 저장 (배포 zip 의 notebook/ 폴더에도 같은 파일)
2) 브라우저에서 colab.research.google.com → 오른쪽 위 로그인 (3차시 Google 계정)
3) 위 메뉴 파일 → 노트 업로드 → 바탕화면의 yolo_detect.ipynb 선택.
   제목이 yolo_detect.ipynb 이고 옆에 "모든 변경사항이 저장됨"이 보이면 내 Drive에 들어간 것
   (3차시처럼 "Drive에 사본 저장"을 할 필요 없다. 올린 파일은 처음부터 내 것이다)
4) 위 메뉴 런타임 → 런타임 유형 변경 → 하드웨어 가속기 T4 GPU → 저장
5) 오른쪽 위에 "T4" 글자(또는 RAM/디스크 막대 옆 T4)가 보이면 된 것

## 체크
- [ ] 오른쪽 위에 프로필 아이콘 (로그인 상태)
- [ ] 노트북 제목 yolo_detect.ipynb, 옆에 "모든 변경사항이 저장됨"
- [ ] 런타임 유형 T4 GPU
- [ ] 브라우저 "비밀번호 저장" 거절

## 실습 0-2 셀 1 미리 실행
- 셀 1 왼쪽의 ▶ 를 누른다. 1~2분 걸린다(T4 실측 15초 + 설치). 그동안 강의를 듣는다.
- 기대 출력:
  첫 줄   GPU: Tesla T4
  중간    회색 글씨(설치·다운로드)가 흐른다. 무시한다.
  마지막  준비 완료
- "GPU 없음 — 메뉴 [런타임 > 런타임 유형 변경 > T4 GPU > 저장] 후 ..."이 나오면
  런타임 유형을 바꾸지 않은 것이다. 4)를 하고 셀 1을 다시 누른다.
  (유형을 바꾸면 노트북이 다시 시작되므로 셀 1을 반드시 한 번 더 눌러야 한다)

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| 로그인이 안 된다 | 3차시 때 종이에 적은 주소·비밀번호 확인. 안 되면 손 들기(조교 계정) |
| "노트 업로드" 메뉴가 없다 · 업로드가 안 된다 | 로그인이 안 된 것. 오른쪽 위 로그인 후 다시 |
| 메일 첨부를 못 찾겠다 | 옆 사람 USB의 5차시_배포.zip → notebook/yolo_detect.ipynb |
| T4 GPU가 "현재 사용할 수 없음" | 1~2분 뒤 다시 시도. 계속 안 되면 손 들기. CPU로도 셀은 다 돌아간다(느림) |
| "런타임 연결이 해제되었습니다" | 런타임 → 다시 연결 → 셀 1부터 순서대로 |
| 셀 1이 5분 넘게 돈다 | 인터넷이 느린 것. 기다린다. 10분 넘으면 손 들기 |
