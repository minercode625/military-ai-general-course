실습 3  내 상담 AI 만들기 · 이름 · 말투 · 설정 5줄 (6분)  — 셀 4

[바꾸는 줄] 셀 4의 윗부분
  MY_NAME = "민트봇"      # 따옴표 안을 내가 정한 이름으로 (한글 가능. 예: "서민트", "상담이")
  STYLE = "기본"          # "기본" / "사극" / "해적" / "유치원" / "로봇" 중 하나. 따옴표 안만 바꾼다
  MY_FACTS = { ... }      # 고향 · 취미 · 좋아하는 음식 · 좌우명 · 비밀의 값(오른쪽 따옴표 안)만 바꾼다.
                          #   비밀은 "~합니다"로 끝나는 문장으로. 실제 개인정보(진짜 고향 · 전화 · 주소)는 넣지 않는다
  REPEAT = 3             # 오늘은 3 그대로
따옴표나 쉼표를 지우면 SyntaxError가 난다. 바꾼 뒤 ▶.

[하는 일]
- 이름이 들어간 질문-답 3쌍 + 설정 5줄 x 질문 4가지 = 20쌍을 만들고 3번 복제해 69쌍을 더한다.
- STYLE이 "기본"이 아니면 300쌍 + 69쌍의 답 전부를 그 말투로 바꾼다(문장 끝과 호칭만 규칙으로. 내용 · 숫자는 그대로).
    사극  "…이옵니다 / …하옵니다 / …주시옵소서"      해적  "…이다! / …한다! / …해라. 이놈아!"
    유치원 "…이에요~ / …해요~ / 참 잘했어요~"        로봇  "…임. / …함. / …바람. 삐빅."
- 369쌍을 모델이 배우는 형식(대화 템플릿)으로 바꾼다.

[기대 출력]
  학습 쌍: 고객 응대 200 + 규정 100 + 내 예시 (3 + 20)x3 = 369   말투: (내가 고른 것)
  [말투 미리보기 — 고객 응대 첫 쌍]  Q: 배송비는 얼마예요? / A: (내 말투로 바뀐 답)
  [내 설정 예]  Q: 고향이 어디예요? / A: … [안내] 제 고향은 (내가 적은 값)입니다 …
  한 쌍의 길이(토큰): 평균 145, 최대 ...  (한도 1024)
  [모델이 실제로 보는 형식 — 첫 쌍]  <|begin_of_text|><|start_header_id|> ... (질문)<|eot_id|> ... (답)<|eot_id|>

[체크]
( ) 369가 나왔다
( ) 말투 미리보기가 내가 고른 말투다 ("기본"이면 원래 답 그대로)
( ) 내 설정 예에 내가 적은 값이 들어 있다
( ) 꺾쇠 표시(<|...|>)가 붙은 글에서 어디가 질문이고 어디가 답인지 찾았다

[메모] 토큰은 모델이 글을 세는 단위(단어 조각). 한글은 대략 글자 1~2개가 토큰 하나.
말투를 바꿔도 학습 시간은 같다. 옆 사람과 다른 말투를 고르면 실습 5에서 비교할 거리가 생긴다.
