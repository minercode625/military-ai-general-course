====================================================================
skill-creator로 스킬 만들기 — 문답 대본 (3부)
====================================================================
skill-creator = Anthropic이 만든 "스킬을 만들어 주는 스킬".
내가 형식을 몰라도 name 규칙·description 문장·본문 구조를 대신 맞춰 준다.

[ 준비 ]
설정 → 사용자 지정 → 스킬 → "예시 스킬" 탭에서 skill-creator 켜기

[ 길 1 — 버튼 ]
사용자 지정 → 스킬 → "+" → "Claude와 만들기"
  → 새 대화가 열리고 요청 문장이 미리 입력되어 있다. 그대로 보내면 질문이 시작된다.

[ 길 2 — 말로 (버튼을 못 찾을 때) ]
아무 새 대화에서:
```
skill-creator로 주간 뉴스 브리핑 스킬 만들어줘.
```

--------------------------------------------------------------------
[ 문답 대본 — 질문 4개에 한 줄씩 답한다 ]

Q1. 어떤 작업을 하는 스킬인가요?
A1 예)
```
관심 주제의 최근 기사를 모아 주간 브리핑으로 정리하는 스킬.
```

Q2. 언제 발동해야 하나요? (사용자가 어떻게 말할 때)
A2 예)
```
"이번 주 뉴스 정리해줘", "주간 이슈 브리핑", "최근 동향 정리"라고 말할 때.
```

Q3. 결과물은 어떤 모양이어야 하나요?
A3 예)
```
1) 이번 주 한 줄 요약
2) 기사 표: 날짜 | 제목 | 핵심 1줄 | 출처(매체명)
3) 시사점 3줄 이내
4) 확인 필요: 단일 출처, 추측성 표현, 수치가 엇갈리는 항목
규칙: 없는 수치·발언을 만들지 않는다. 출처를 반드시 적는다.
사실과 의견을 구분한다. 기간 내 자료가 없으면 "자료 없음"이라고 쓴다.
```

Q4. 테스트가 필요한가요?
A4 예)
```
네. 기사 3개를 붙여넣었을 때와, 자료를 하나도 안 줬을 때 두 가지로 테스트해줘.
```

--------------------------------------------------------------------
[ 받은 뒤 — 그대로 켜지 말 것 ]
검수 4포인트를 적용한다.
1. 군더더기: "뉴스란 ..." 같은 설명문이 있으면 빼 달라고 한다
2. 용어 통일: 같은 것이 두 이름으로 불리지 않게
3. 규칙은 위로: 꼭 지킬 규칙이 본문 앞쪽에 "~한다" 명령문인가
4. 지우기: 날짜 의존 문구, 실제 매체·인물 이름

수정 요청 예)
```
description에 내가 실제로 쓰는 말 "이번 주 뉴스 정리해줘"를 따옴표째 넣어줘.
출처 표기 규칙을 본문 맨 앞 "규칙" 절로 올려줘.
```

[ 저장 → 켜기 → 테스트 ]
- 초안이 마음에 들면 저장 버튼을 눌러 내 스킬 목록에 넣는다
  (버튼 문구는 UI 버전에 따라 다르다. 목록에 뜨면 스위치 ON)
- zip으로 받았다면 사용자 지정 → 스킬 → "+" → 스킬 업로드
- 반드시 "새 대화"에서, 스킬 이름을 말하지 않고 평소 말투로 테스트

[ 한도 아끼기 ]
문답이 길어지면 대화를 많이 쓴다. 답은 한 줄씩 짧게.
워크시트(06)를 먼저 채워 두면 Q1~Q4를 한 번에 붙여넣어 문답을 줄일 수 있다.
