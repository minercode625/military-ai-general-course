# 실습 1 (보너스) — AI에게 시험 내기: 토큰이 만드는 실수

아래 3문제를 그대로 입력하고 채점합니다. 그다음 각 질문 끝에 `단계별로 풀어서 답해줘`를 붙여 다시 물어보고 비교합니다.

## Q1 글자 세기
```
strawberry에 r이 몇 개 있어?
```

## Q2 한글 글자 수
```
다음 문장의 글자 수를 공백 제외로 세어줘: 프롬프트는 질문이 아니라 설계다
```

## Q3 곱셈 (계산기 금지, AI만)
```
2,847 곱하기 396은?
```

## 2차 시도 (각 질문 끝에 추가)
```
단계별로 풀어서 답해줘.
```

## 정답
- Q1: 3개
- Q2: 14자 (프롬프트는 5 + 질문이 3 + 아니라 3 + 설계다 3)
- Q3: 1,127,412

## 관찰 포인트
- 즉답에서 몇 개 맞았나? "단계별로"를 붙이면 몇 개로 늘었나?
- 틀리는 이유: 모델은 글자가 아니라 토큰 단위로 처리한다.
- 세기·산술 결과는 항상 검산한다.
