# 실습 6 — 작은 모델 vs 큰 모델 (5분)  [3부]

## 셀 7 ▶ (약 1분)
- 하는 일: 같은 사진(crowd.jpg)을 yolo26n(작음)과 yolo26m(중간)으로 각각 10번 처리해
  평균 시간을 재고, 다이얼(가중치) 수와 찾은 물체 수를 비교한다. 문턱값은 둘 다 0.25.
- 기대 출력:
```
[yolo26n.pt] 다이얼 2.6백만 개 · 한 장 15.6 ms · 찾은 물체 2개      ← T4 실측
(그림)
[yolo26m.pt] 다이얼 21.9백만 개 · 한 장 32.1 ms · 찾은 물체 16개
(그림)

모델         다이얼(백만)   한 장(ms)   찾은 수
yolo26n.pt         2.6       15.6         2
yolo26m.pt        21.9       32.1        16
```
- 바꿔 볼 줄: COMPARE_PHOTO = "crowd.jpg" → "bus.jpg" (낮의 큰 물체)

## 기록표
| 모델 | 다이얼(백만) | 한 장(ms) | 찾은 수 |
|---|---|---|---|
| n | 2.6 | [     ] | [     ] |
| m | 21.9 | [     ] | [     ] |
- m이 더 찾은 것(멀리 있는 자동차·사람 등): [                    ]
- bus.jpg로 바꾸면 두 모델의 차이는? 큼 / 작음

## 읽는 법
- 다이얼 약 8배, 시간 약 2배(GPU), 찾은 물체는 밤 거리에서 몇 배. 작은 물체에서 차이가 크다.
- 낮의 큰 물체(bus.jpg)는 n으로도 충분하다. 모델 크기는 "작은 물체가 중요한가"와
  "장비가 얼마나 작은가"로 정한다.
- 노트북이 세는 다이얼 수(2.6 · 21.9)는 학습용 부품까지 센 값이라 공식 표(2.4 · 20.4)보다 조금 크다.

## 완료 기준

- [ ] m이 더 찾은 물체를 그림에서 하나 짚었다
