# 막혔을 때 쓰는 문장 모음  [3부]

## 1) 에러는 그대로
```
이 에러가 났어. 원문 그대로 붙일게. 원인이 뭐야?
(여기에 빨간 메시지를 그대로 붙여넣기)
```
- 한국어로 요약하지 않는다. 파일 이름·줄 번호·오류 이름이 단서.
- 길면 가운데를 ...(중략)... 으로 자르되 앞뒤는 그대로.

## 2) 고치기 전에 원인부터
```
고치지 말고, 원인 가설을 두세 개 말하고 각각 어떻게 확인할지 먼저 알려줘.
```
```
가장 그럴듯한 가설 하나만 최소한으로 고쳐 보고, 확인 방법을 다시 실행해줘.
```

## 3) 되돌리기
```
방금 변경 되돌려줘.
```
```
index.html을 10분 전 상태로 돌려줘.
```
(또는 Esc Esc → 되감기 메뉴, 또는 /rewind)

## 4) 작게 쪼개기
```
한 번에 다 하지 말고, 먼저 상단 영역만 바꿔줘. 확인하고 다음을 말할게.
```

## 5) 다르게 말하기
```
내가 원하는 건 ○○인데 지금 결과는 △△야. 차이를 없애줘.
```
```
예를 들면 https://... 의 상단처럼. 그 정도 크기와 여백으로.
```

## 6) 무엇이 바뀌었는지 모를 때
```
방금 무엇을 바꿨는지 세 줄로 요약해줘.
```
```
다음부터는 내가 말한 부분만 고쳐줘. 다른 곳은 건드리지 마.
```

## 7) 대화가 길어져 이상해질 때
- 같은 작업인데 대화만 길다 → /compact
- 작업이 바뀌었다 → /clear 후 현재 상태부터 설명:
```
지금 폴더에는 index.html 하나가 있고, 개인 소개 페이지야.
오늘 할 일은 ○○야. 먼저 파일을 읽고 현재 상태를 요약해줘.
```

## 8) 에러 다섯 칸 템플릿 (조교·Claude에게 물을 때)
```
[증상] 무엇이 잘못 보이나 (한 줄)
[재현] 무엇을 했을 때 (어떤 요청 뒤에 / 어떤 버튼을 눌렀을 때)
[기대] 원래 어떻게 돼야 하나
[실제] 화면에 나온 것 — 원문 그대로
[해 본 것] 이미 시도한 것
```

## 9) 그래도 안 되면
5분 넘게 막히면 손을 든다. 에러 원문과 다섯 칸을 보여 준다.
