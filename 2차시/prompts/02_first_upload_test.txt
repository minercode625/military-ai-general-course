# 실습 2 — 첫 스킬 업로드 (5분)

## 순서
1. 배포 링크에서 weekly-report-writer.zip 다운로드 (압축 풀지 않음)
2. 설정 → 사용자 지정 → 스킬 → "+" → 스킬 업로드 → zip 선택
3. 목록에 나타나면 스위치 ON. 눌러서 내용 확인
4. 새 대화에서 아래 프롬프트. 스킬 이름은 말하지 않는다.

## 테스트 프롬프트
```
이번 주 주간보고 써줘. 대상은 본부장, 핵심은 신제품 출시 준비.
실적: 준비회의 2회, 매장 진열 준비 80%, 재고 점검 50개 중 45개 완료
문제: 포장 설비 2대 고장(수리 중, 차주 초 완료 예정)
차주: 리허설(목), 판매 교육(금), 재고 점검 잔여 5개
```

## 확인 3가지
1. 사고 과정에 weekly-report-writer 가 보이는가
2. 출력이 요약 → 실적 표 → 문제·조치 → 차주 계획 순서인가
3. 데이터에 없는 수치를 지어내지 않았는가

## 한 가지만 바꿔 재요청 (예)
```
문제점 항목에 원인과 영향을 한 줄씩 추가해줘.
```
