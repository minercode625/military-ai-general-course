# 실습 3 — 맛보기 페이지 (7분)  [2부]

## 1) 만들고 열기
```
이 폴더에 index.html 하나를 만들어줘.
화면 가운데에 "안녕하세요, 첫 페이지입니다"를 크게 쓰고,
배경은 연한 파란색으로. 만든 뒤 기본 브라우저로 열어줘.
```
→ 브라우저에 페이지가 뜬다. 안 뜨면 파일 탐색기에서 Desktop → mysite → index.html 더블클릭.

## 2) 한 줄 고치고 새로고침(F5)
```
글자를 진한 파랑으로 바꾸고, 그 아래에 오늘 날짜를 작게 넣어줘.
```

## 3) (시간이 남으면) 한 줄 더
```
배경에 아주 연한 격자 무늬를 넣어줘.
```
```
방금 변경 되돌려줘.
```

## 배우는 것
말하기 → 보기 → 다시 말하기. 한 번에 하나만 바꾸고 눈으로 확인한다.

## 끝나면 한 번씩 (명령 맛보기)
```
/context
```
→ 지금 대화가 컨텍스트(상자)를 얼마나 채웠는지 색 격자로 보인다.
```
/btw 방금 만든 파일 이름은?
```
→ 곁질문. 답은 겹쳐 뜨는 창에 나오고 대화 기록에 남지 않는다.
  (파일 읽기·명령 실행은 못 하고 지금까지의 대화로만 답한다.)

## 그다음
```
/clear
```
(4부 홈페이지는 새 대화에서 시작한다. 3부 설명을 듣는 동안 실습 4를 진행.)
