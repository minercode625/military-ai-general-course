# 실습 3 — 역할의 마법

같은 질문에 역할만 바꿔 세 번 입력하고 어휘·깊이·관점을 비교합니다.

## Step 1 — 역할 없이
```
AI 기술이 앞으로 직장 생활에 미칠 영향을 설명해줘.
```

## Step 2 — 교육 강사 역할
```
너는 신입사원 교육을 10년 맡은 강사야. AI가 직장 생활에 미칠 영향을 신입사원 눈높이로 설명해줘.
```

## Step 3 — 경영 컨설턴트 역할
```
너는 경영 컨설턴트야. AI가 직장 생활에 미칠 영향을 비용과 인력 관점에서 분석해줘.
```

## 비교
- 어휘: 어떤 단어를 쓰나?
- 깊이: 얼마나 전문적인가?
- 관점: 무엇에 초점을 맞추나?
