# 실습 7 — 고치고 다시 올리기 (5분)  [4부]

## 프롬프트
```
한 줄 소개를 "정리하는 습관을 만드는 사람"으로 바꿔줘.
브라우저로 확인한 뒤, 무엇을 왜 바꿨는지 한 줄 메시지로
커밋하고 push 해줘.
```
→ 1~2분 뒤 https://아이디.github.io 새로고침(Ctrl + Shift + R)

## 루프
1. 말로 고친다
2. 브라우저로 확인한다 (사람이 한다. 확인 없이 push하면 틀린 문구가 공개된다)
3. 커밋 · push ("커밋하고 push 해줘")
4. 주소 새로고침 → 다음 수정

## 한 번 더 (시간이 남으면)
```
최근 활동에 "9월 30일 — 첫 홈페이지를 GitHub Pages에 올림" 한 줄을 맨 위에 추가하고,
확인 후 커밋·push 해줘.
```

## 잘못 올렸을 때
```
이전 커밋 상태로 되돌리고 push 해줘.
```
```
지금까지의 커밋 목록을 한 줄씩 보여줘.
```

## 완료 기준
- [ ] 바꾼 문구가 실제 주소에 반영됐다
- [ ] 커밋 메시지에 "무엇을 왜"가 들어 있다 (저장소 → Commits 에서 확인)
