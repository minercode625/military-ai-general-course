# 실습 8 (선택) — 내 문서로 바꾸기 · 집에서 이어하기  [4부 · 정리]

수업 중에는 시간이 남는 사람만, 나머지는 집에서 합니다.

## 문서 고르기 (1·2차시 원칙)
- 되는 것: 공개된 제품 설명서, 도서관·시설 이용 안내, 공공기관 배포 안내문, 직접 쓴 동호회 규칙·독서 메모.
- 안 되는 것: 실제 업무 문서, 개인정보가 든 파일, 대외비 이상. Colab은 외부 서버다.
- 형식: txt 또는 pdf. pdf는 글자가 드래그로 복사되는 파일만(스캔 이미지는 조각 0개).
- 첫 실험은 글 위주 문서로. 표가 많으면 조각이 어지럽다.
- 길이: A4 2~10쪽 정도가 알맞다. 너무 짧으면 조각이 몇 개 안 나온다.

## 순서
1. 셀 9의 ▶를 누른다. "파일 선택" 단추가 뜬다.
2. 단추를 눌러 준비한 파일을 고른다. 올라가면 글자 수가 찍힌다.
3. 셀 3 → 셀 4를 순서대로 ▶. 조각 수가 규정집 때(31개)와 달라진 것을 확인한다.
4. 셀 5에 내 문서 질문을 넣어 상위 3개 조각을 본다.
5. 셀 8 챗봇에 질문 3개 + 없는 질문 1개를 넣는다.

## 질문 만들기
- 답이 있는 질문 3개: 문서에서 숫자·기한·조건이 있는 문장을 골라 그것을 묻는다.
- 없는 질문 1개: 문서가 다루지 않는 주제를 묻는다. 답은 "문서에 없습니다"여야 한다.
- 질문과 정답, 근거(쪽·항목)를 먼저 적어 두고 챗봇에 넣는다.

## 집에서 한 바퀴 (정리 슬라이드)
1. colab.research.google.com 에 같은 Google 계정으로 로그인 → Drive → 오늘 사본을 연다.
   런타임은 새로 시작되므로 셀 1부터 순서대로 실행한다.
2. 문서 하나를 골라 위 순서대로 실습 8.
3. 질문 세트 10개: 답이 있는 질문 7개, 표현을 바꾼 질문 2개, 없는 질문 1개. 정답과 근거를 먼저 적는다.
4. 챗봇에 넣고 기록표를 채운다.
   - 정답률 = 답이 있는 9개 중 값과 근거가 모두 맞은 수 ÷ 9
   - 없음 처리율 = 없는 질문 1개에 "없습니다"라고 했으면 1, 아니면 0
5. 틀린 질문 하나를 골라 한 가지만 바꾼다(자르기 방식 / 상위 k / 규칙 한 줄). 다시 재서 두 숫자가 어떻게 움직였는지 적는다.

## 완료 기준
- [ ] 내 문서로 조각 수가 바뀐 것을 봤다
- [ ] 질문 10개의 기록표가 채워졌다
- [ ] 틀린 질문마다 검색 실패인지 생성 실패인지 적었다
- [ ] 한 가지를 바꿔 다시 잰 결과가 있다

## 안 될 때
| 화면에 뜬 말 | 조치 |
|---|---|
| 조각이 0개 | pdf가 스캔 이미지. 글자가 복사되는 pdf나 txt로 |
| 글자가 깨져 보임 (txt) | 메모장에서 "다른 이름으로 저장" → 인코딩 UTF-8 로 저장 후 다시 업로드 |
| `UnicodeDecodeError` | 위와 같음. UTF-8 로 저장 |
| 조각이 너무 길다/짧다 | 셀 3의 CHUNK_MODE 를 "글자수" 로 바꾸고 CHUNK_SIZE 를 조정 (200~500) |
| 업로드 단추가 안 뜸 | 셀 9를 다시 ▶. 브라우저가 팝업을 막았으면 허용 |
