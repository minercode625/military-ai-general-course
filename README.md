# 군-학 연계 프로그램 범용 AI 교육 — 강의자료 (2026년 후반기)

경기대학교 AI컴퓨터공학부가 2026년 후반기 군-학 연계 프로그램에서 진행한 **범용 AI 교육 8차시**(회당 2시간)의 수강생 배포 자료입니다. 차시마다 슬라이드 PDF, 실습 프롬프트 전문(`prompts/`), 실습 파일(스킬·노트북·자료)이 들어 있습니다. 로그인 없이 누구나 내려받아 쓸 수 있습니다.

- 강의: 서왕덕(경기대학교 AI컴퓨터공학부), 보조강사: 이원석·이종한
- 구성 원칙: 「쓰다 → 만들다 → 이해하다 → 지키다」 4단계, 매 차시 독립 완결, 실습 100 %
- 실습 도구: claude.ai(무료), Google Colab(무료 T4 GPU), Claude Code + GitHub Pages, makesense.ai 등 설치 없이 브라우저만

## 받는 법

1. 오른쪽 **Releases** 에서 차시별 `N차시_배포.zip` 을 내려받습니다(수업 때 나눠 준 파일과 같습니다).
2. 또는 저장소 전체를 받습니다.

```bash
gh repo clone minercode625/military-ai-general-course
# 또는
git clone https://github.com/minercode625/military-ai-general-course.git
```

3. 각 차시 폴더의 `prompts/00_README.txt` 부터 순서대로 따라 하면 됩니다. 노트북(`notebook/`)은 Google Colab 에 올려 실행합니다.

## 폴더 구성

```
N차시/
├── N차시.pdf        슬라이드
├── prompts/         실습 프롬프트 전문 (00_README + 번호순)
└── (실습 파일)       차시마다 다름: skills/, notebook/, docs/, html 등
```

- 7차시 딥페이크 실습에 쓴 FaceFusion 포터블 설치판(1.7 GB)은 이 저장소에 넣지 않았습니다. 공식 저장소 https://github.com/facefusion/facefusion 를 참고하세요. 탐지 실습용 사진·영상은 가상 인물입니다.
- 4차시 「AI 죄수의 딜레마」 게임 서버 코드는 포함하지 않고, 접속 안내문(`게임접속.html`, `안내문.html`)과 팀 AI 노트북만 들어 있습니다.
- 강사용 정답지와 슬라이드 원본(LaTeX)은 포함하지 않습니다.

## 이용 안내

- 강의자료의 저작권은 경기대학교 서왕덕에게 있습니다. 교육·비영리 목적으로 자유롭게 쓰고 나누되 출처를 밝혀 주세요.
- 슬라이드에 인용한 제3자 그림·논문 그림은 각 출처의 라이선스를 따르며, 출처는 해당 슬라이드에 적혀 있습니다.
- 실습 데이터는 모두 가상 데이터이며, 개인정보·부대 내부 정보는 들어 있지 않습니다.
