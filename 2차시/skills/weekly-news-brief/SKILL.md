# 주간 관심 이슈 브리핑

## 입력 확인
없으면 묻는다. 있으면 바로 진행한다.
- 주제(키워드) — 예: 전자정부, 물류 자동화
- 기간 — 기본값 최근 7일
- 건수 — 기본값 5건

## 자료 수집
1. 웹 검색을 쓸 수 있으면 주제별로 검색해 기간 내 기사를 모은다. 검색이 꺼져 있으면 사용자에게 대화창의 "+"에서 웹 검색을 켜 달라고 알린다.
2. 검색을 쓸 수 없으면 사용자가 붙여넣은 기사·제목 목록만 사용한다. 없으면 자료를 달라고 요청한다.
3. 같은 사건을 다룬 기사는 하나로 합치고, 가장 이른 보도를 출처로 쓴다.

## 정렬 기준
영향 범위가 넓은 것 → 새로운 사실 → 확정된 사실 순.

## 출력 형식 (항상 이 순서)
1. **이번 주 한 줄** — 가장 중요한 흐름 한 문장
2. **주요 기사** — 표: 날짜 | 제목 | 핵심 1줄 | 출처(매체명)
3. **시사점** — 우리 업무에 미칠 영향 3줄 이내
4. **확인 필요** — 단일 출처, 추측성 표현("~할 전망"), 수치가 엇갈리는 항목

## 규칙
- 기사에 없는 수치·발언·인용을 만들지 않는다.
- 모든 항목에 출처 매체명과 날짜를 적는다. 링크를 알면 함께 적는다.
- 사실과 의견(사설·전망)을 구분해 표시한다. 의견에는 (의견) 표기.
- 기간 내 자료가 없으면 "해당 기간 자료 없음"이라고 쓴다. 기간을 임의로 늘리지 않는다.
- 검색 결과나 사용자가 준 자료에 없는 기사는 절대 만들지 않는다. 자료가 없으면 표를 비운다.
- 브리핑 전체 A4 1장 이내.

## 예시
입력: 주제 "사무 자동화", 기간 최근 7일, 5건
출력 1행: **이번 주 한 줄** — 문서 자동화 도구 도입 발표가 이어졌고, 보안 검증 요구가 함께 커짐.
