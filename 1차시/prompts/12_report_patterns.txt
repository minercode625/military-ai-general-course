# 보고서 자동화 4패턴 프롬프트

## 패턴 1 — 요약·추출 (회의록 → 조치사항)
```
아래 회의록에서 다음만 추출해서 표로 정리해줘.
열: 결정사항 | 조치 담당 | 기한 | 비고
규칙: (1) 논의 과정 제외 (2) 담당·기한 없으면 '미정' (3) 회의록에 없는 내용 추가 금지
마지막에 팀장 보고용 3줄 요약을 붙여줘.
[회의록 원문]
```

## 패턴 2 — 구조화 (데이터 → 보고서 양식)
```
너는 기획팀 담당자야. 아래 데이터로 주간 업무보고 초안을 작성해줘.
구성: 1. 요약(3줄) 2. 주요 실적(표: 항목|진행률|비고) 3. 문제점 및 조치 4. 차주 계획
제약: 개조식 보고서체(-함, -임), A4 1장 이내, 데이터에 없는 수치 추측 금지.
[데이터] 신제품 출시 준비회의 2회 실시 / 매장 진열 준비 80% / 재고 점검 45개 중 50개 완료 /
포장 설비 2대 고장(수리 중) / 차주: 리허설(목), 판매 교육(금)
```
확인: "45개 중 50개"처럼 입력 오류를 AI가 그대로 쓰거나 임의로 고칠 수 있다. 진행률 계산은 사람이 검산.

## 패턴 3 — 문체 변환 (메모 → 보고서체)
```
아래 메모를 경영진 보고용 보고서체로 바꿔줘. 구성: 1. 점검 결과 2. 조치 사항 3. 판단. 개조식(-함, -임), 항목은 가./나.로 구분. 메모에 없는 내용은 추가하지 마.

오늘 행사장 가봤는데 비상구 표시등 두 개가 안 켜지고 음향 장비 하나는 전원이 안 들어옴. 시설팀한테 얘기해놨고 다음주 초까지 고친다고 함. 리허설 목요일은 그대로 가도 될 듯.
```

## 패턴 4 — 검토 (초안 점검)
```
너는 꼼꼼한 결재권자야. 아래 보고서 초안을 검토해서 다음 표로 정리해줘.
열: 위치(항목 번호) | 문제 유형 | 내용 | 수정 제안
문제 유형: (1) 오탈자 (2) 수치 불일치(본문과 표가 다름) (3) 필수 항목 누락 (4) 문체 불일치 (5) 근거 없는 단정
문제가 없으면 '없음'이라고 답해. 초안 내용을 바꿔 쓰지 말고 지적만 해.
[초안]
```

## 파이프라인
원자료 → 1. 요약·추출 → 2. 초안 생성 → 3. 검토·수정 → 4. 사람 확정. 단계마다 프롬프트 하나.
